# 저장·다시 열기 사용자 시나리오 검수 — 2026-10-22

현재 소스의 Chrome 렌더러를 격리된 Playwright 프로필에서 검수했다. 실제 사용 중인 앱이나 문서는 조작하지 않았으며, 공개 배포 파일과 리토스 문서는 변경하지 않았다.

## 확인한 흐름

- 7장짜리 업무 보고 자료: 한글 제목·발표자 노트·빈 줄, 부분 서식 글머리표, 중첩 그룹 도형, 회전된 삼각형, 표와 일부 셀의 기울임꼴, 잘라낸 PNG, 그라데이션, 페이드, 외부/슬라이드 링크, 숨긴 부록.
- 실제 화면에서 제목과 노트를 수정한 뒤 **PPTX 저장 버튼으로 파일을 다운로드하고 그 파일을 다시 여는 흐름을 3회** 반복했다. 각 파일은 테스트 출력 폴더에 실제로 저장했다.
- 마지막 PPTX의 Slide Studio 전용 메타데이터를 제거해 다시 읽어도 표·그룹·글머리표·링크·이미지 자르기·노트·숨김·전환이 유지되는지 확인했다. 저장된 내용이 전용 JSON에만 의존하지 않음을 확인한 검사다.
- 저장 전후 제목 슬라이드 화면을 확인했다. 재개방 후 표 편집 창에서 머리글/줄무늬 체크 상태와 실제 색상 변경도 확인했다.

## 수정한 문제

### 1. 일부 셀에 서식을 적용한 표의 머리글·줄무늬 설정 소실

재현: 머리글과 줄무늬가 있는 표의 `Alpha Beta` 중 `Beta`에 기울임꼴·다른 색을 적용하고 PPTX로 저장한 뒤 다시 연다. 머리글과 줄무늬 설정이 모두 꺼지고, 원래의 배경색은 셀별 고정 서식으로 남아 표 전체 설정을 바꿔도 의도대로 동작하지 않았다.

원인: 단순 서식 전용 빠른 경로가 부분 서식을 만나면 일반 표 가져오기로 넘어갔고, 이 경로는 표 기본 설정을 버리고 모든 셀에 계산된 서식을 고정했다.

수정: 유효한 표 기본 설정은 유지하되 실제 셀 내용과 서식은 DrawingML에서 읽는다. 기본 설정과 같은 셀별 덮어쓰기만 제거해 머리글/줄무늬 설정이 다시 적용되게 했다. 외부 프로그램에서 수정한 셀 내용·색·기울임꼴·머리글 플래그가 오래된 메타데이터에 의해 되돌아가지 않는 검사도 통과했다.

재검증: 동일한 표를 3회 저장·재개방하고 화면의 체크 상태를 확인한 후 두 옵션을 껐을 때 머리글과 줄무늬 배경이 흰색으로 바뀌는 것을 확인했다.

### 2. 빈 표 셀의 입력 서식 소실

재현: 흰색 굵은 글씨의 빈 머리글 셀과 빨간색·기울임꼴·36px로 지정한 빈 본문 셀을 저장하고 표의 전용 메타데이터를 제거해 다시 연다. 빈 머리글 셀이 검은색 일반 글씨로 바뀌었다.

원인: 생성 라이브러리가 빈 셀의 입력 서식을 표준 텍스트 XML에 남기지 않았다.

수정: 빈 셀에도 글꼴·색·굵기·기울임·정렬을 담은 빈 텍스트 런을 기록한다. 불투명도 60%인 표를 반복 저장할 때 빈 런의 불투명도가 36%로 중복 적용되지 않도록 명시된 빈 런도 표 불투명도 정규화에 포함했다.

재검증: 전용 메타데이터 없이 재개방한 뒤 다시 3회 저장·재개방해 빈 셀의 입력 서식과 실효 불투명도 60%가 유지됨을 확인했다.
