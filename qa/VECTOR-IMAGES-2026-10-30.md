# 벡터 그림 표시 개선 계획과 검증

기준: GitHub `d473b6f` / 개발 버전 1.6.16. 공개 릴리스와 리토스 다운로드 문서는 이 작업에서 갱신하지 않습니다.

## 목표와 실행 순서

PPTX를 열었을 때 로고·아이콘·도식이 빠지는 문제를 우선 해결합니다. 이번 범위는 벡터 그림 표시이며, 오디오 재생과 개체 애니메이션 엔진은 포함하지 않습니다.

1. **누락 재현**: SVG 단독 그림, Office SVG 확장과 PNG 대체 그림, EMF, WMF가 포함된 PPTX를 만듭니다. 수정 전에는 4개 중 PNG 대체 그림 1개만 편집 화면으로 가져옵니다.
2. **SVG 표시·삽입**: 정적인 SVG 그림을 독립된 이미지로 표시하고 그림 삽입·교체, 자르기·회전·뒤집기, 배경과 마스터·레이아웃 상속에 연결합니다. Office SVG 확장을 PNG 대체 그림보다 우선합니다.
3. **EMF·WMF 변환**: 앱에 포함된 브라우저 변환기로 SVG를 만듭니다. 별도 프로그램 설치 없이 실행하고, 워커·시간·크기 제한과 가져오기 단위의 중복 변환 캐시를 적용합니다. 실패하면 Office 대체 그림을 사용합니다.
4. **왕복·실행 검증**: 같은 파일을 편집·실행 취소·다시 실행·PPTX 저장·재열기·발표·PDF 출력으로 확인합니다. 원본 벡터 바이트도 비교하고, 공개 실무 샘플과 반복 벡터가 있는 다수 슬라이드로 회귀 검사합니다.

## 구현

- `src/svg-image.ts`: SVG 구문 검사와 DOMPurify 정제, 정적인 로컬 스타일·그라데이션·클리핑 유지, 외부 참조·이벤트·스크립트·외부 HTML 차단, 크기와 캐시 제한.
- `src/vector-image.ts`, `src/metafile.worker.ts`: 실제 바이트로 EMF/WMF를 판별하고 레코드 경계를 검사한 뒤 워커에서 SVG로 변환합니다. 워커는 완료·실패 시 종료합니다. `emf-converter` 4.24.0을 고정하고 브라우저 전용 진입점을 번들링합니다.
- `src/import-image.ts`, `src/image-format.ts`: 그림·배경·영상 포스터·삽입·교체가 같은 디코더를 사용합니다. 기존 PNG/JPEG/GIF/WebP 바이트와 TIFF 변환은 유지합니다.
- `src/io.ts`: SVG 확장 우선 선택, 대체 그림 처리, 변환 성공·실패 캐시, SVG 모델 검증과 원본 보존 연결.
- `src/pptx-preservation.ts`: 원본 벡터 바이트와 개체 바인딩을 유지하고 EMF/WMF의 일반 확장자 형식 선언도 함께 기록합니다. 정확한 개별 파트 MIME Override도 유지합니다.
- `electron/main.cjs`: 번들 안의 blob 워커를 허용합니다. 임의 inline/eval 스크립트나 외부 네트워크는 허용하지 않습니다.
- 런타임 의존성의 라이선스와 변환기에 포함된 제3자 고지를 앱에 포함합니다.

## 검증 결과

- 수정 전 재현: 4개 시험 그림 중 1개만 가져옵니다. 수정 후 4개 모두 표시하고 세 번 저장·재열기해도 원본 SVG/EMF/WMF 바이트가 동일합니다.
- 벡터 전용 14개 시나리오를 두 번 실행: **28개 통과, 실패·제외·불안정 결과 0개**. 직접 삽입한 SVG/EMF/WMF의 저장·재열기, 표준 및 placeable WMF, 슬라이드·레이아웃·마스터의 그림/배경, 깨진 SVG 대체 그림, 외부 요청 차단, 실제 편집·발표 화면을 포함합니다.
- 100장·400개 벡터 그림 시험을 두 번 수행했습니다. 각 가져오기에서 고유 EMF와 WMF를 합쳐 워커 2회만 실행했습니다. 가져오기 약 0.29–0.32초, 저장 약 0.93–0.95초, 재열기 약 0.27–0.28초였습니다. 같은 작은 벡터 자원을 반복한 시험이며 임의의 대용량 실무 파일 성능을 의미하지 않습니다.
- 공개 EMF/WMF 샘플 4개: 그라데이션·클리핑·그리기 상태·도형·패턴·비트맵의 비어 있지 않은 렌더링을 확인하고 PNG를 눈으로 검토했습니다. 출처와 라이선스는 `tests/fixtures/vector/`에 포함합니다.
- 공개 PPTX 3개, 총 34장: 실제 UI 열기와 PPTX 저장·재열기에서 텍스트·그림 수 유지, JavaScript 오류 0개. 기존 실무 샘플의 내장 EMF 2개도 변환 경로에 포함합니다.
- macOS 패키지: 임시 프로필에서 실제 파일 열기, 프로덕션 CSP 아래 워커 변환, 편집·실행 취소·다시 실행, 원본 벡터 해시 보존, 저장·재열기, 실제 PDF 생성과 인쇄 DOM 정리를 검증합니다. 파일 대화상자 응답만 QA 프로세스에서 대체하며 사용자 문서는 변경하지 않습니다.

- **최종 관련 회귀 검사 101개 통과**: 실패·제외·불안정 결과 0개, 약 3분 33초. 최종 벡터 15개 시나리오, 원본 보존, 배경, 그림 편집, JSON 유효성, GIF·동영상, 앱 간·슬라이드 클립보드, 네이티브 파일 동작과 저장·재열기를 포함합니다.
- 최종 Mac 패키지의 벡터 워크플로 5개와 GIF·MP4·WebM의 실제 정지 미리보기/발표 재생·반복·자동 저장 복원을 통과했습니다. JavaScript·CSP 오류 0개. 최종 PDF를 PNG로 변환해 그림 4개와 한글 표시를 확인했습니다.
- 최종 네이티브 저장 PPTX의 스키마·관계·콘텐츠 형식 검사를 원본을 기준으로 실행해 모두 통과했습니다. `tsc`, 프로덕션 빌드, 새 모듈의 Prettier, 변경 파일의 공백 검사도 통과했습니다.
- 로컬 앱 교체 상태와 패키지 해시는 Git 추적에서 제외한 `qa/results/vector-images/final-status.json`에 기록합니다. 공개 릴리스·다운로드 파일·리토스 문서는 변경하지 않습니다.

## 범위와 한계

- SVG와 지원하는 EMF/WMF는 확대 가능한 **그림 개체**입니다. 그림 내부 경로나 글자를 각각 편집하는 기능은 아닙니다.
- SVG는 4 MiB·20,000개 하위 요소, EMF/WMF는 16 MiB·50,000개 최상위 레코드로 제한합니다. 변환 시간은 내부 5초·워커 외부 8초로 제한하며 전체 자산 용량 제한도 계속 적용합니다.
- SVG의 기본 이미지 크기는 한 변 2048로 제한하되 viewBox와 벡터 좌표는 유지합니다. 확대 표시에 이 기본 픽셀 크기를 고정 해상도로 사용하는 것은 아닙니다.
- 일부 GDI/EMF+ 레코드·효과, 외부 리소스와 설치되지 않은 원본 글꼴은 원본과 다를 수 있습니다. SVG 내부 글꼴은 시스템에서 사용할 수 있는 글꼴을 사용합니다.
- 잘못된 벡터는 파일 안의 대체 그림으로 표시합니다. 유효한 대체 그림도 없으면 호환성 안내와 함께 제외합니다.
- 이전 버전에서 이미 손실된 원본 데이터를 복원하지는 않습니다. 원래 PPTX를 새 앱으로 다시 여는 것을 권장합니다.
- Windows/Linux에서 직접 실행하거나 Microsoft PowerPoint에서 화면을 비교한 결과는 이 작업에 포함하지 않습니다. 실제 Mac 패키지와 Chrome에서 검증합니다.
