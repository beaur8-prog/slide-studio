# macOS 파일 선택창과 파일 작업 상태

- 개발 버전: **1.6.21**.
- 대상: 파일 열기, PPTX 다른 이름으로 저장, 공통 macOS 파일 패널 준비.
- 공용 최근 폴더·iCloud 북마크·전역 설정을 삭제하거나 재설정하지 않았습니다. 기존 문서·복구 데이터 처리도 유지합니다.

## 확인한 경로와 수정

기존 코드는 마지막 문서 폴더를 `defaultPath`로 전달했지만 Cocoa 패널 생성 전에 `NSOSPLastRootDirectory`를 지정하지 않았습니다. 이 Mac의 Slide Studio 전용 설정에도 해당 값이 북마크 데이터로 남아 있었습니다. 공용 기록은 이미 복구된 상태이므로 기존 `DownloadCloudDocumentSync` 대기를 고의로 다시 만들지는 않았습니다.

`electron/file-dialogs.cjs`에서 실제 패널 호출 전에 `systemPreferences.setUserDefault('NSOSPLastRootDirectory', 'string', app.getPath('home'))`를 호출합니다. Electron의 앱 전용 `NSUserDefaults`만 변경합니다. 현재 파일·마지막 문서의 폴더를 제안하는 `defaultPath`는 유지합니다. PPTX·PDF·복구 원문 저장이 같은 준비 함수를 사용합니다.

실제 OS 시험에서는 프레젠테이션 형식 필터가 정상 PPTX의 **Open** 버튼과 PPTX 저장 창의 **Save** 버튼을 막는 현상도 확인했습니다. 한글·영문 이름과 로컬 임시 경로에서 확인했고, 실제 호출에서 필터만 제외한 대조 시험에서는 같은 파일이 열렸습니다. macOS의 PPTX·기존 `.slide` 패널은 네이티브 형식 필터를 제외합니다. 이 창에는 다른 종류의 파일도 보이지만, 선택 후 메인 프로세스가 확장자·256 MiB 한도를 검증합니다. 저장기는 `.pptx` 확장자와 덮어쓰기 충돌·외부 변경 검사를 유지합니다. Windows·Linux 및 PDF·복구 파일의 형식 필터는 유지합니다. [Electron 파일 필터 API](https://www.electronjs.org/docs/latest/api/dialog)를 참고했습니다.

열기 요청 직전에 대기를 표시하고 참조 가드를 즉시 설정해 빠른 중복 클릭·단축키를 차단합니다. 열기 중 새 문서·다른 파일 작업·발표도 시작하지 않습니다. 취소·오류·완료는 `finally`에서 대기를 해제합니다. 다른 이름으로 저장에도 선택창 대기 문구를 표시합니다. 메인 프로세스의 파일·인쇄·캡처 중복 방지는 유지합니다.

실패한 OS 파일 요청은 오류를 알린 뒤 멈춥니다. effect 의존성을 스스로 갱신해 영구 오류를 무한 재시도하던 경로를 제거했습니다. 새 OS 요청은 다시 처리할 수 있습니다.

## 검증 결과

- 관련 자동 검사 **40개 통과**. 패널 생성 전 앱 전용 경로 지정, 기본 경로·플랫폼별 필터, 중복 요청, 취소·오류 후 재요청, 무한 재시도 방지, 미저장 편집·파일 컨텍스트·외부 변경·복구 원문 보존과 발표 격리를 포함합니다.
- 빌드·JavaScript 구문·Mac 번들 임시 서명의 엄격 검증 통과. 기존 Vite 청크 크기 안내는 남아 있습니다.
- 실제 설치 앱 **1.6.21**을 별도 시험 프로필에서 실행하고, 응답을 모의 처리하지 않은 macOS 선택창을 직접 조작했습니다.
- **열기 → 취소 → 다시 열기 → 한글 PPTX 선택·열기** 통과. 취소 뒤 기본 문서와 편집 화면이 유지되고 선택한 파일의 제목·본문·도형이 표시됐습니다.
- **다른 이름으로 저장 → 취소 → 다시 열기 → 새 한글 이름으로 저장** 통과. 두 저장 패널이 원본 폴더를 제안했고, 취소 뒤 원본을 유지하며 완료 뒤 새 파일 컨텍스트·저장 완료 표시를 확인했습니다.
- 실제 패널 네 번 모두 호출 직전 앱 전용 시작 경로가 일반 문자열인 사용자 홈 경로임을 기록했습니다. 요청은 각각 정상 취소 또는 완료됐습니다.
- 원본 PPTX의 SHA-256 유지, 원본·저장본 OOXML 검증, 시험 슬라이드 전체의 실제 앱 시각 확인을 통과했습니다. 정상 종료 후 별도 프로필의 복구 보존 표식도 유지됐습니다.
- 원래 실행 앱이 저장된 기본 제목 슬라이드 한 장임을 확인하고 정상 종료했습니다. 1.6.20은 `~/Library/Application Support/Slide Studio Backups/file-panels-1.6.21-20261031/Slide Studio.app`에 보존했습니다. OS 저장 시험에 원래 사용자 프로필을 사용하지 않았으며, 시험 후 일반 프로필의 최종 1.6.21 앱을 실행했습니다.

## 결과 파일과 재검사

원본 결과는 `qa/results/file-panels-20261031/`, 사용자 작업 폴더의 사본은 `qa/file-panels-20261031/`입니다. `native-panels.json`은 실제 패널 기록, `native-profile.json`은 복구 표식 결과, `final-tests.json`은 자동 검사, `packaged-source.json`은 설치된 패키지와 소스의 일치 기록입니다.

`node scripts/qa-file-panels-native.cjs '/Applications/Slide Studio.app/Contents/MacOS/Slide Studio'`로 별도 프로필에서 수동 OS 패널 시험을 기록합니다. 실제 창에서 위 순서를 수행하고 앱 메뉴로 정상 종료합니다. 원래 사용자 프로필이나 공용 설정을 지우지 않습니다.

공개 Release·다운로드·리토스 문서는 변경하지 않았습니다. Windows 설치 파일 재빌드와 배포는 이번 macOS 수정 작업에 포함하지 않습니다.
