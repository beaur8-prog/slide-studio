# Slide Studio 1.4.2 검증 기록

2026-10-18(KST), macOS arm64에서 검사했습니다. 이 배포는 편집 화면의 마우스 휠 반응을 개선합니다.

## 원인과 수정

기존에는 휠 입력을 60px까지 모은 뒤 장을 넘기고, 전환 후 350ms 동안 추가 입력을 버렸습니다. 새 편집기는 12px부터 반응하며 고정 대기 시간을 없앴습니다. 80ms보다 긴 입력 간격이나 방향 반전을 새 동작으로 보고, 연속된 관성 입력은 한 장만 넘깁니다. 확대 상태의 내부 스크롤, Ctrl/Meta+휠 확대, 왼쪽 목록과 텍스트 편집 보호는 유지합니다. 발표 모드의 휠 기준은 바꾸지 않았습니다.

동일한 20px 입력을 120ms 간격으로 보낸 비교입니다. 초기 장은 1번이며 예제는 4장입니다.

| 휠 입력 | 1.4.1 | 1.4.2 |
| --- | ---: | ---: |
| 첫 번째 | 1 | 2 |
| 두 번째 | 1 | 3 |
| 세 번째 | 2 | 4 |
| 네 번째 | 2 | 4 (마지막 장) |

이는 해당 입력 크기에서의 재현 결과입니다. 마우스 드라이버와 운영체제의 휠 설정은 서로 다를 수 있습니다.

## 자동 검사

프로덕션 빌드가 통과했고 전체 Playwright 검사 **90개 통과, 2개 제외, 실패·불안정 검사 0개**를 확인했습니다(143.2초). 제외 항목은 실제 Windows 창 크기와 Office 글꼴 캐시를 요구합니다.

새 검사는 작은 휠 입력·빠른 별도 조작·방향 반전·줄 단위 입력, 작은 떨림과 600ms의 연속 관성 입력을 확인합니다. 기존 확대 화면 스크롤·Ctrl+휠·장 양 끝·목록·스크롤바·발표·파일·한글 조합 이벤트 검사도 통과했습니다. 연속 입력 검사는 각 입력 사이에 검증 대기가 끼어 새 동작으로 분리되지 않도록 30ms 간격으로 명시했습니다.

1.4.1의 공개 PPTX 5개·465장 전체 검사와 별도 메모리 계측은 이번에 반복하지 않았습니다. 해당 수치와 이전 Mac 저장·내보내기 확인은 [1.4.1 검증 이력](RELEASE-1.4.1.md)에 있습니다.

## 실제 Mac 앱

배포 ZIP을 새 임시 폴더에 풀어 서명을 검사한 뒤 기존 앱과 사용자 프로필을 백업하고 `/Applications/Slide Studio.app`을 1.4.2로 교체했습니다. 설치한 ASAR은 두 배포 ZIP과 같습니다.

기존 5장짜리 문서가 열렸고 저장 완료 표시를 확인했습니다. 네이티브 스크롤 API의 작은 동작(0.1페이지)으로 1→2→3→2장 이동을 확인했습니다. 왼쪽 목록에서 스크롤해도 편집 장은 바뀌지 않았습니다. 문서 내용을 편집하지 않았으며 원래 작업하던 5번 장과 화면 맞춤 86% 상태로 돌려놓았습니다. 실제 물리 마우스의 한 클릭을 계측한 검사는 아니며, 정확한 20px 입력 비교는 별도 자동 검사입니다.

## 패키지

두 ZIP의 전체 CRC32 검사와 프로덕션 ASAR 검사를 통과했습니다. 버전 매니페스트는 1.4.2이며 자산·Electron 셸 23개 파일이 작업 사본과 바이트 단위로 같습니다. 공통 ASAR SHA-256은 `eb5a8fa501cdaf68397a2deec606204004238c855b239c0cb53417dc24efeb39`입니다. Mac 추출본과 설치본은 strict 코드 서명 검사를 통과했고, Windows는 공식 Electron 42.11.15의 체크섬·PE x64 구조·필수 파일·메타데이터와 원본 코드 섹션을 검증했습니다.

| 파일 | 바이트 수 | SHA-256 |
| --- | ---: | --- |
| Slide-Studio-mac-arm64.zip | 128862995 | `c320af92c911d9a9e0051ac8629027477ce969a7dd9e825bbeb3b686a6eb1c2d` |
| Slide-Studio-win-x64.zip | 156035910 | `35a5f07815ded8a95adf4382286c0cf30037be9970882b5de1775233d7643927` |

기존 `releases/latest/download/` 파일 이름과 리토스 공유 문서 주소를 유지합니다. 문서 본문은 기존 공유 항목의 `ShareServer.update`(공유본 갱신)로 버전·변경 사항·검증 범위를 갱신하며, 공유 서버나 터널을 재시작하지 않습니다.

## 검증 범위

이번 Windows ZIP의 실제 Windows 실행은 수행하지 않았습니다. Mac은 ad-hoc 서명이며 공증하지 않았고 Windows는 배포 서명이 없습니다. 실제 OS IME 조합 입력과 종이 출력은 미검증입니다.

로컬 증거는 `qa/results/release-1.4.2/`, 휠 전후 비교는 `qa/results/wheel-response/comparison.json`, 공유 문서 갱신 증거는 `qa/results/release-1.4.2-document/`에 있습니다. 생성된 결과와 사용자 문서·공유 설정은 Git에 포함하지 않습니다.
