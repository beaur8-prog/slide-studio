# 도형 서식과 패널 닫기 개선

2026-10-21. 다음 배포용 소스 변경. 공개 설치 파일과 리토스 문서는 갱신하지 않는다.

## 재현과 수정

- 개체 서식 제목에 같은 X 아이콘이 두 개 있었다. 뒤쪽 X는 선택을 해제해 슬라이드 서식으로 전환했다. 선택 해제 X를 제거하고 패널 닫기 하나만 유지한다. 닫았다 다시 열어도 개체 선택이 유지된다.
- 패널의 정렬 버튼들이 한 줄로 나열되어 내부 너비가 255px인데 내용은 449px까지 늘어났다. 정렬 도구를 그리드로 배치하고 숫자 입력과 레이어 이름의 최소 너비를 제한했다. 수정 후 내용 너비와 패널 너비가 255px로 일치한다.
- 홈에 도형 채우기·채우기 없음·선 색·선 두께를 추가했다. 오른쪽 패널과 같은 동작을 사용하며 잠긴 개체·텍스트·이미지를 변경하지 않는다. 단색 채우기를 적용하면 기존 그라데이션을 해제하고, 보이지 않는 선에 색이나 두께를 지정하면 다시 표시한다.
- 홈의 도형 서식 행은 도형을 선택하지 않았을 때도 비활성 상태로 유지한다. 선택 도중 리본 높이가 바뀌어 캔버스 좌표와 드래그 선택이 어긋나는 것을 방지한다.

## 검증

도형 서식·숫자 입력·그룹 선택·텍스트와 도형 색·화면 구성·발표자 노트 크기·도형 조절값 관련 30개 검사 중 29개가 첫 수정 후 통과했다. 나머지 하나는 PPTX가 색상 코드를 대문자로 정규화하고 선 두께에 약 0.00005px 단위 변환 오차를 남기는 것을 검사에서 고려하지 않은 문제였다. 색상은 대소문자를 정규화하고 두께는 0.001px 이내로 비교하도록 수정한 뒤 신규 도형 서식 검사 3개가 모두 통과했다. 프로덕션 빌드도 통과했다.

신규 검사는 닫기 동작과 선택 유지, 970·1080·1280·1540px 창 너비에서 패널과 홈 도구의 가로 넘침 없음, 홈/패널 값 동기화, 실행 취소, PPTX 저장·재가져오기, 그라데이션 제거, 다중 선택·잠금 개체 제외 및 0 두께 선 복구를 확인한다. 캡처 화면도 검토했다.
