# Slide Studio 1.6.2

2026-10-19. 도형 조절값 보존과 GIF·동영상 재생을 포함하는 배포다.

## 변경

- 삼각형 꼭짓점, 굵은 화살표의 몸통·머리, 원호·리본·말풍선 등 원본 도형 조절값을 경로에 적용한다. 곡선·음영·외곽선·연결선 화살촉도 보존한다.
- GIF 원본 프레임과 반복 설정을 유지한다. MP4(H.264)·WebM(VP8/VP9)을 삽입하고 발표 중 자동 시작·반복·음소거를 설정한다. 편집·썸네일·PDF·인쇄에는 영상의 정지 미리보기를 쓴다.
- 내장 영상 원본과 단순 재생 설정을 PPTX에 보존한다. 영상은 한 개당 20 MiB, 이미지·영상 합계는 100 MiB다. 지원 범위를 넘는 영상은 정지 미리보기와 안내로 대체한다.
- 불러오기 완료 팝업을 제거했다. 호환성 안내는 필요할 때 하단의 **가져오기 안내**에서 연다.
- 발표 화면 오른쪽 아래 노트 버튼을 제거했다. 기존 노트 편집·별도 발표자 창·O 단축키는 유지한다.
- 기존 Studio 표 교환과 편집 기능을 포함한다. 별도로 추가된 Windows DRM 가져오기 구현은 이 저장소에 없으므로 이번 배포에 포함하지 않는다.

## 검증

도형 187종의 세 비율, 조절 가능한 123종의 조절값 300개·1,800개 조건, 삼각형 꼭짓점 7개 위치와 점 편집 경로를 검사했다. 프로젝트 및 PPTX 저장 왕복과 편집·발표 화면을 확인했다. [상세 도형 검사](SHAPES-MEDIA-2026-10-19.md)에 범위와 이전 공개 버전 비교가 있다.

Mac ARM64 ZIP, Windows x64 Setup 및 portable ZIP, Linux amd64 DEB를 같은 실행 코드로 만든다. 배포 전 전체 회귀 검사와 패키지 해시·구성·버전 검사를 수행하고, Windows 및 Ubuntu 22.04/24.04의 실제 설치 앱에서 편집·발표·GIF/MP4/WebM 프레임 변화·반복·자동 저장 복원을 확인한다. 최종 결과는 검증 후 이 문서에 기록한다.

Mac 앱은 Apple 공증을 받지 않았고 Windows 앱은 배포용 코드 서명이 없다. 다운로드 경고 및 **Windows의 PC 보호 → 추가 정보 → 실행** 안내를 다운로드 문서에 유지한다. Microsoft PowerPoint의 모든 조판·개체 애니메이션, 외부 미디어·오디오·복잡한 영상 타이밍은 지원하지 않는다. 실제 Windows 10/11의 SmartScreen 화면 수동 클릭, 키보드 IME 직접 입력, Wayland 및 종이 출력은 이번 자동 검사 범위에 포함하지 않는다.
