# 도형 서식과 패널 닫기 개선

2026-10-21의 초기 기능 수정은 1.6.7에 배포했다. 2026-10-22의 리본 배치 변경은 다음 배포용 소스이며 공개 설치 파일과 리토스 문서는 갱신하지 않는다.

## 재현과 수정

- 개체 서식 제목에 같은 X 아이콘이 두 개 있었다. 뒤쪽 X는 선택을 해제해 슬라이드 서식으로 전환했다. 선택 해제 X를 제거하고 패널 닫기 하나만 유지한다. 닫았다 다시 열어도 개체 선택이 유지된다.
- 패널의 정렬 버튼들이 한 줄로 나열되어 내부 너비가 255px인데 내용은 449px까지 늘어났다. 정렬 도구를 그리드로 배치하고 숫자 입력과 레이어 이름의 최소 너비를 제한했다. 수정 후 내용 너비와 패널 너비가 255px로 일치한다.
- 홈에 도형 채우기·채우기 없음·선 색·선 두께를 추가했다. 오른쪽 패널과 같은 동작을 사용하며 잠긴 개체·텍스트·이미지를 변경하지 않는다. 단색 채우기를 적용하면 기존 그라데이션을 해제하고, 보이지 않는 선에 색이나 두께를 지정하면 다시 표시한다.
- 홈의 도형 서식 행은 도형을 선택하지 않았을 때도 비활성 상태로 유지한다. 선택 도중 리본 높이가 바뀌어 캔버스 좌표와 드래그 선택이 어긋나는 것을 방지한다.

## 검증

도형 서식·숫자 입력·그룹 선택·텍스트와 도형 색·화면 구성·발표자 노트 크기·도형 조절값 관련 30개 검사 중 29개가 첫 수정 후 통과했다. 나머지 하나는 PPTX가 색상 코드를 대문자로 정규화하고 선 두께에 약 0.00005px 단위 변환 오차를 남기는 것을 검사에서 고려하지 않은 문제였다. 색상은 대소문자를 정규화하고 두께는 0.001px 이내로 비교하도록 수정한 뒤 신규 도형 서식 검사 3개가 모두 통과했다. 프로덕션 빌드도 통과했다.

신규 검사는 닫기 동작과 선택 유지, 970·1080·1280·1540px 창 너비에서 패널과 홈 도구의 가로 넘침 없음, 홈/패널 값 동기화, 실행 취소, PPTX 저장·재가져오기, 그라데이션 제거, 다중 선택·잠금 개체 제외 및 0 두께 선 복구를 확인한다. 캡처 화면도 검토했다.

로컬 증거: `qa/results/shape-format/`의 `baseline.log`, `final.log`, `focused.log`, `build.log`와 각 검사 출력 폴더. 이번 변경의 Windows/Linux 설치판 직접 실행 검증은 하지 않았다.

## 2026-10-22 홈 리본 배치

도형 서식을 홈의 글꼴과 단락 사이에 같은 리본 그룹으로 배치했다. 채우기·채우기 없음·선 색·두께는 두 줄로 묶고 그룹 이름은 다른 도구와 같은 아래쪽 위치에 둔다. 별도의 전체 너비 행을 제거해 홈 리본 높이는 135px에서 97px로 줄었다. 선택 여부에 따른 높이 변경은 없다.

작은 창에서는 글꼴 입력 너비·도구 간격을 줄이며 모든 명령과 입력란을 표시한다. 970·1080·1100·1200·1250·1280·1540px에서 글꼴 → 도형 서식 → 단락 순서, 같은 줄 배치와 높이 97px, 가로 넘침과 입력란 잘림 없음을 확인했다. 처음에는 1100px에서 8px 가로 넘침을 발견해 작은 창용 배치 적용 범위를 1150px까지 넓혔다.

관련 회귀 검사 33개 중 32개가 처음 통과했고, 위의 가로 넘침 수정 뒤 도형 서식 검사 3개가 모두 통과했다. 글자 부분 서식·숫자 입력·그룹 선택·노트·화면 구성·색상/두께 동기화·실행 취소와 PPTX 왕복을 포함한다. 프로덕션 빌드도 통과했다. 로컬 증거는 `qa/results/home-shape-ribbon/`에 있다.

Mac 앱 번들도 별도 검증 프로필에서 실행해 리본 순서·높이와 홈 도형 서식, 실제 PPTX 저장·재열기·최근 파일 처리를 확인했다. 공개 배포 파일의 기존 SHA-256이 그대로임을 확인했다.
