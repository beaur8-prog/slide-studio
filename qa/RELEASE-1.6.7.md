# Slide Studio 1.6.7

PPTX 그림 배경·0 크기 도형 호환성, 실제 최근 파일 목록, 도형 서식 개선.

- 슬라이드·레이아웃·마스터 그림 배경을 자르기·불투명도와 함께 읽고 편집 화면·축소판·발표·인쇄에 표시한다. 저장한 PPTX에는 실제 그림 배경으로 보존한다. 단색 배경으로 변경하거나 실행 취소할 수 있다.
- 너비·높이가 0인 원본 도형 때문에 문서 전체 열기가 실패하지 않도록 수정했다. 원본 경로와 크기를 유지하며 보이는 외곽선만 선으로 표시한다.
- 홈에서 도형 채우기·채우기 없음·선 색·두께를 바꿀 수 있다. 서식 패널은 가로로 넘치지 않으며 X를 누르면 선택을 유지한 채 닫힌다.
- 앱 재실행·새 편집 창은 매번 빈 슬라이드 한 장으로 시작한다. 같은 창의 새로고침은 임시 편집 상태를 복원한다.
- 내 프레젠테이션은 디스크의 실제 파일 목록이며 동일 경로를 중복 표시하지 않는다. 삭제·이동된 원본은 목록에서 제외하며 내부 사본으로 대신 열지 않는다. 파일별 편집 사본을 새로 쌓지 않으며, 구버전 내부 데이터는 자동 삭제하지 않는다. 종료 전 PPTX로 저장해야 한다.

세부 수정·선행 검증: [그림 배경](PICTURE-BACKGROUNDS.md), [0 크기 도형](ZERO-SIZE-SHAPES.md), [홈 도형 서식](SHAPE-FORMAT-CONTROLS.md), [저장·실행·최근 파일](PPTX-SAVE-AND-FOLDERS.md).

Mac·Windows·Linux 배포 파일과 실제 설치 앱을 검증했다. 기존 리토스 공유 링크와 고정 다운로드 주소를 유지하며 Windows 설치 안내를 맨 위에 둔다. Mac은 Apple 미공증, Windows는 배포용 코드 미서명으로 보안 경고가 표시될 수 있다.

공통 회귀 검사 60개, 삼각형 꼭짓점 검사 5개와 프로덕션 빌드가 통과했다. 최근 파일·배경·도형·저장 폴더·부분 글자 서식·숫자 입력·글머리표·노트·스크롤·발표 격리를 검사했으며 전체 앱 테스트 모음을 모두 다시 실행한 결과는 아니다. 배경·0 크기 도형 수정 때 확인한 공개 샘플 5개의 열기·렌더링·PPTX 저장/재가져오기는 위의 선행 검증 기록에 있다.

배포 파일 네 개의 실행 코드 SHA-256과 소스 파일 54개가 일치한다. Mac ZIP을 다시 풀어 코드 서명 무결성도 검증했다. Apple 공증을 뜻하지 않는다. 설치 앱 결과와 패키지 SHA-256은 아래에 기록한다. 모든 PowerPoint 효과·글꼴·조판 일치를 보장하지 않으며 Windows/Linux 실제 키보드 IME 직접 타이핑·Wayland·종이 출력은 검증 범위에 포함하지 않는다.

## 설치 앱 검증 방식

Windows·Ubuntu 설치판과 Mac 배포 번들은 별도 검증 프로필에서 실행한다. 그림 배경이 있는 마스터와 0 크기 도형으로 만든 재현 PPTX를 열고, 자르기·불투명도·원본 이미지 바이트와 크기를 검사한 뒤 실제 PPTX 저장·재열기를 확인한다. 홈의 도형 채우기·선·두께, 패널 너비·닫기 후 선택 유지와 실제 최근 파일 중복 제거·삭제 항목 제외도 검사한다.

Mac에서는 완전 종료·재실행, 창 닫기 후 활성화·두 번째 인스턴스 요청에 의한 창 재열기가 빈 문서로 시작하는지 추가 검사했다. 같은 창의 새로고침은 편집 상태를 복원하며 최근 항목은 디스크의 바뀐 내용을 읽는다. 원본이 삭제되면 내부 사본으로 열지 않는다.

파일 대화상자 응답은 검사용으로 지정하고 실제 IPC·파일 입출력을 검사한다. OS 파일 대화상자를 직접 클릭한 수동 시험은 아니다. 삼각형 드래그 검사는 macOS의 비동기 전체 화면 종료와 캔버스 크기가 안정된 뒤 좌표를 측정하도록 보완했다. 모델 좌표·이동량·실행 취소·PPTX 왕복 검증은 유지한다.

## 공개 배포 확인

[GitHub v1.6.7](https://github.com/beaur8-prog/slide-studio/releases/tag/v1.6.7)을 공개하고 [기존 리토스 다운로드 문서](https://pink-photos-barrel-activation.trycloudflare.com/s/209727b046a226e48d2c00d344cf6facbd4bdb99d62595a6)를 같은 URL·토큰·생성일로 갱신했다. 공유 서버와 터널을 재시작하지 않았다. 새 기능과 매 실행 빈 문서·실제 최근 파일·종료 전 PPTX 저장 안내, 최신 설치 앱 화면을 반영했다. Windows 설치 경고를 맨 위에 유지했다.

공개 문서 본문과 이미지 파일 22개가 검토본과 일치한다. 데스크톱·모바일에서 모든 그림이 로드되고 가로 넘침·브라우저 오류가 없음을 확인했다. 고정 latest/download 주소 5개에서 파일을 끝까지 다시 받아 바이트 수·SHA-256·GitHub digest와 v1.6.7 리다이렉트를 확인했다. 증거는 `qa/results/release-1.6.7/publication-verification.json`, `live-update.json`, `native/`에 있다.

현재 버전만 남기는 기존 정리 방침에 따라 1.6.6의 GitHub 첨부 파일 5개와 이전 리토스/publication 이미지 폴더를 삭제했다. 이전 릴리스 설명과 Git 태그, 현재 1.6.7 다운로드는 보존했다. 이 Mac의 설치 앱도 1.6.7로 교체하고 기존 원본 IXPE 파일을 다시 열어 그림 배경 표시를 확인했다. 원본 문서는 변경하지 않았다.
