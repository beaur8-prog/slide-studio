# 긴 텍스트·차트 안내·실무형 PPTX 회귀 보완

2026-10-18 개발 수정입니다. 공개 배포와 리토스 공유 문서는 갱신하지 않았습니다.

## 수정한 동작

- 기존 텍스트 상자는 줄바꿈이 기본으로 켜져 있지만 고정 높이에 의해 긴 글의 아래쪽이 잘릴 수 있었습니다. 고정 상자의 잘림을 재현하고 자동 높이를 켠 뒤 전체 글자가 보이는지 확인하는 검사를 추가했습니다.
- 새로 삽입하는 텍스트 상자는 줄바꿈과 자동 높이가 기본으로 켜집니다. 기존 상자는 서식에서 두 설정을 선택할 수 있습니다. 실제 렌더링 높이를 저장하므로 편집 화면·선택 테두리·PPTX 출력 높이가 일치합니다. 높이를 직접 입력하거나 세로 크기를 끌어 조절하면 자동 높이가 해제됩니다.
- 자동 높이는 가로쓰기·한 단 상자에서 지원합니다. 원본 PPTX는 자동으로 재배치하지 않습니다. 자동 높이 설정은 .slide에 저장하고 PPTX에는 계산된 높이를 보존합니다. 슬라이드의 경계를 넘어갈 만큼 긴 글은 글자 크기나 내용을 조절해야 합니다.
- 차트 삽입 창 상단에서 **데이터 연동 안 됨**, 엑셀·원본 숫자 변경 시 자동 갱신되지 않음, 값 수정 시 다시 삽입해야 함을 삽입 전에 안내합니다.
- 원본의 `numCol`·`spcCol`을 읽지 않던 문제를 수정했습니다. 마스터·레이아웃 상속을 포함해 단 수와 간격을 가져와 표시하고 네이티브 PPTX 속성으로 다시 내보냅니다. 다단 텍스트의 원래 높이는 유지합니다.

## 추가한 실무형 공개 자료

출처·파일 크기·SHA-256·구조를 [workplace-samples.json](workplace-samples.json)에 고정했습니다. `python3 scripts/fetch-qa-samples.py`로 확보하고, 원본 해시가 바뀌면 검사를 중단해 검토하도록 했습니다. 다운로드한 원본 파일은 Git에 재배포하지 않습니다.

추가 자료의 모든 장에서 원본 OOXML 텍스트와 가져온 텍스트를 대조하고, 프로젝트·PPTX 왕복 후 글자·비연결선 개체의 위치·크기를 비교합니다. 비대칭 표 테두리가 명시적 선 개체로 내보내지는 차이는 예상한 테두리 수로 검증합니다. 새 공개 자료에는 다단 본문이 없어 별도의 마스터 상속·두 단·고정 줄 간격 원본 XML 회귀 사례도 추가했습니다. 기존 중첩 그룹 회전·뒤집기 및 마스터 그림 관계 검사는 계속 실행합니다.

## 검증 결과

- `npm run build`가 통과했습니다.
- 긴 한글·띄어쓰기 없는 한글, 입력·삭제·폰트 크기·너비 변경에 따른 높이, 수동 높이 및 실행 취소, 설정 저장·재열기와 PPTX 높이 보존을 확인합니다.
- 실제 Mac 로컬 앱의 서명과 빌드 파일 일치를 확인하고 정상 종료 후 수정본으로 교체했습니다. 기존 5장 문서를 유지한 채 다시 실행했고, 실제 앱에서 차트 안내와 줄바꿈·자동 높이 설정도 확인했습니다.
- 공개 Mac ZIP·Windows ZIP·Setup 파일의 SHA-256이 이전 1.5.6 배포와 동일함을 확인했습니다. 리토스 다운로드 문서도 변경하지 않았습니다.
- **전체 회귀 검사 176개 통과·환경 의존 2개 생략·실패 0개**(178개, 약 6.2분). 관련 항목 34개의 선행 검사도 통과했습니다. 새로 추가한 회귀 사례 8개를 포함하며, 기존 부분 글자색·우클릭·표·휠·발표·가져오기 검사도 통과했습니다.

로컬 증거는 `qa/results/text-layout-fix/`에 보관합니다(Git에서 제외). 원본 글꼴 캐시와 실제 Windows 전체 화면 등 환경 의존 항목은 이 Mac에서 생략되며, 이번 수정본을 Windows 실기에서 실행했다고 주장하지 않습니다.

## 범위와 한계

추가 자료의 대표 화면도 렌더링해 검토하지만 모든 원본을 Microsoft PowerPoint에서 다시 열어 픽셀 단위로 비교한 것은 아닙니다. 네이티브 차트 데이터 등 기존 미지원 기능은 가져오기 경고를 유지합니다. 실제 개인·회사 파일 전체의 호환성을 보장하지 않습니다. 원본 글꼴이 없는 기기의 줄바꿈과 PowerPoint 고유 조판 차이는 남을 수 있습니다.
