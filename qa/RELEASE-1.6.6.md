# Slide Studio 1.6.6

2026-10-21. PPTX 저장 통일, 문서 폴더 기억과 첫 실행 빈 문서.

- 파일 메뉴·빠른 저장·상단 버튼·명령 검색·Ctrl/⌘+S·OS 파일 메뉴가 PPTX로 저장한다. 별도 PPTX 내보내기와 `.slide` 생성은 제거했다. 기존 `.slide` 파일은 열어 PPTX로 옮길 수 있다. 원본 파일을 자동 변환하거나 지우지 않는다.
- 문서를 열거나 PPTX 저장에 성공한 폴더를 다음 파일 대화상자의 시작 위치로 사용하고 재실행 후에도 기억한다. PDF는 현재 문서 폴더를 사용하며 기억된 폴더를 바꾸지 않는다. 취소·실패는 폴더를 바꾸지 않으며, 폴더가 없어지면 Documents를 사용한다.
- 처음 실행하면 텍스트·도형·노트 없는 빈 슬라이드 한 장으로 시작한다. 기존 자동 저장 작업은 복원하며 예제는 새 문서 메뉴에서 선택한다.
- 확장자가 없거나 다른 확장자를 입력하면 `.pptx`를 붙인다. 추가된 확장자의 실제 경로가 이미 존재하면 덮어쓰기를 확인한다. 저장 중 반복 명령은 중복 실행하지 않는다.

[소스 변경 검증](PPTX-SAVE-AND-FOLDERS.md)에 세부 동작과 선행 검사를 기록했다. 공통 회귀 검사 44개와 프로덕션 빌드가 통과했다. Windows 전용 네이티브 전체 화면 검사 한 개는 Mac에서 건너뛰며 실제 설치판을 별도로 검사한다. 네 패키지의 버전·동일 실행 코드·소스 파일 일치·SHA-256과 Mac·Windows·Ubuntu 설치 앱을 검증했다.

Mac·Windows·Linux의 고정 다운로드 주소와 기존 리토스 공유 URL을 유지한다. Windows 설치 안내를 맨 위에 두고, 다운로드 경고·PC 보호 → 추가 정보 → 실행 안내를 유지한다. Mac은 Apple 미공증, Windows는 배포용 코드 미서명이다.

PowerPoint의 모든 글꼴·효과·조판 일치, Windows/Linux 실제 키보드 IME 직접 타이핑, Wayland와 종이 출력은 검증 범위에 포함하지 않는다. 사용 중인 Mac 앱은 문서 보존을 위해 화면이 잠겨 있으면 교체하지 않는다.

## 공통 회귀 검사

저장 명령 전체·중복 저장·PPTX 재가져오기·이전 `.slide` 읽기, 파일 대화상자 폴더·재실행·취소/실패·사라진 폴더·설정 저장 실패·확장자와 덮어쓰기, 한글/300장 편집·자동 저장 복원, 스크롤·발표/판서·노트 높이·화면 구성을 검사했다. 이번 배포에서 전체 앱 검사 모음을 모두 다시 실행한 결과는 아니다. 로컬 결과는 `qa/results/release-1.6.6/`에 있다.

Mac 배포 앱은 별도 임시 프로필에서 최초 빈 문서, 실제 네이티브 IPC를 통한 PPTX/PDF 저장·PPTX ZIP 검사·이전 문서 원본 보존·현재 폴더 사용과 설정 저장, 자동 저장 복원, GIF/MP4/WebM 재생·반복·종료, 삼각형 원본 점/드래그·실행 취소·PPTX 왕복, 노트 높이와 표 32pt × 4행/전체 128pt를 확인했다. 파일 선택 창의 응답은 검사용으로 지정했으며 OS 대화상자를 직접 클릭한 수동 시험은 아니다.
