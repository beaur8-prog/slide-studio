# 삽입 기능 검증 — 1.5.0

검증일: 2026-10-18. Windows x64, 설치된 Chrome과 Microsoft PowerPoint를 사용했습니다.

## 추가 기능

- 표: 최대 20행 × 12열, 셀 텍스트, 행·열 추가/삭제, 머리글·줄무늬, 글꼴·색상·정렬·여백. 많은 행에는 기본 크기를 자동 조절합니다. 삽입 후 더블클릭/Enter로 재편집하며 한 번의 적용은 하나의 실행 취소 단계입니다.
- 차트 4종, 다이어그램 4종, 아이콘 16종, 추가 도형 14종, WordArt 4종, 수식·분수·기호. 삽입 미리보기와 최종 결과는 같은 요소를 사용합니다.
- 사진 앨범: 최대 20장, 슬라이드당 1·2·4장, 순서 변경과 파일명 설명.
- 스크린샷: 창 또는 화면을 사용자가 선택한 뒤 PNG로 삽입합니다. 브라우저에서는 이미지 파일을 선택합니다.
- 웹/슬라이드 링크, 날짜, 슬라이드 번호와 바닥글. 링크는 발표 중 마우스와 키보드로 사용할 수 있습니다.
- 삽입 명령은 Ctrl+K 검색에서도 실행할 수 있습니다.

## 호환성과 실제 화면

8장짜리 검증 파일을 만들어 `.slide`와 PPTX로 저장했습니다. 3×3 한글 표, 20×12 최대 표, 양수/음수 막대 차트, 원형 차트, 프로세스, 분수, 14종 도형, 조직도를 포함합니다. 모든 장에 날짜·번호·바닥글을 넣고 내부/외부 링크도 포함했습니다.

- 앱 재가져오기: 8장, 실제 표 2개, 필드 24개, 링크 3개 유지, 경고 0개.
- Windows PowerPoint에서 복구 메시지 없이 열렸습니다. 8장을 모두 화면으로 확인했으며 표의 한글 줄바꿈·행 높이, 20×12 표의 한 줄 텍스트, 차트 범례, 도형·분수·바닥글에 눈에 띄는 잘림이나 누락이 없었습니다. 기본 표는 PowerPoint 접근성 트리에서도 실제 표로 인식되었습니다.
- 31장 생성 조합의 PPTX 왕복에서 개체·자유형 경로 개수가 유지되고 이미지로 변환되지 않았습니다.
- 1440×900 / 1024×768의 밝은·어두운 테마에서 삽입 리본과 링크·날짜·앨범 화면을 확인했습니다. 화면 밖 누출과 페이지 오류가 없으며 키보드로 리본 항목에 접근할 수 있습니다.
- 실제 Electron 데스크톱 캡처로 검증용 창의 1724×1080 PNG를 삽입했습니다. 이어서 Windows 전체 화면 발표와 Esc 복귀를 확인했습니다.

검증 산출물은 무시 경로 `qa/results/insert-final/`, 화면 점검은 `research/insert-review/`에 저장했습니다. 사용자 문서나 캡처 화면은 저장소·배포 앱에 포함하지 않습니다.

## 회귀 검사

`npm run build`가 통과했습니다. 새 검사는 표 편집·이동·크기 변경·저장/재열기, PPTX 실제 표, 차트/다이어그램/기호 생성, 링크, 바닥글 번호, 사진 앨범과 취소, 스크린샷 선택을 다룹니다.

- 첫 전체 실행은 113개 중 111개 통과했습니다. 한 검사는 시간 제한을 초과했고, 발표 탐색 한 검사는 실행 중 소스 변경으로 개발 서버가 다시 로드되어 실패했습니다.
- 두 번째 전체 실행은 62개 통과와 화면·브라우저 준비 시간 초과 2개 이후 중단했습니다. 추적 기록에서 잘못된 화면 상태나 소스 재로드는 확인되지 않았습니다.
- 소스를 고정한 최종 집중 실행은 **35개 모두 통과**했습니다. 앞서 실패한 네 검사, 표·링크·바닥글·앨범·PPTX 왕복, 실제 배포 파일 로딩, 발표 탐색과 전체 화면 회귀 검사를 포함하며 시간 제한은 검사당 90초였습니다. 결과 경로는 `qa/results/insert-final-focused/`입니다.
- 표를 극단적으로 축소·확대해도 글꼴·여백·테두리 값이 저장 가능한 범위를 벗어나지 않으며, `.slide`와 PPTX로 다시 열립니다. 링크·바닥글 창에서는 한글 조합 중 Escape가 작성 내용을 지우지 않고, 일반 Escape는 창을 닫습니다.
- 표 편집창의 마지막 키보드 보완 후 표 검사 **5개 모두 통과**했습니다. Chromium IME 조합 API로 한글 조합을 시작해 Escape 뒤 내용 유지와 확정을 확인하고, 구형 IME의 229 키 코드, Tab·Shift+Tab 순환, 취소 후 이전 포커스 복원도 검사했습니다. 실제 Windows 한글 입력기 전체 조작을 대신하는 검사는 아닙니다. 이후 최종 `npm run build`도 통과했습니다.

Windows 배포 앱을 설치·실행한 뒤 기존 16장 사용자 문서의 복원, 저장 상태, 새 삽입 리본과 표 편집창을 확인했습니다.

비동기 사진 처리와 캡처를 취소한 뒤 늦게 완료된 결과가 문서에 삽입되지 않는지 확인합니다. 사진 앨범의 미리보기 URL은 변경·닫기 시 해제합니다. 캡처 원본 선택권은 최대 24개·60초·한 번만 유효하며, 메인 프로세스에 NativeImage나 PNG 데이터를 캐시하지 않습니다. 장시간 모든 작업의 메모리 누수 부재를 증명한 검사는 아닙니다.

## 범위

표는 실제 PowerPoint 표로 내보냅니다. 앱이 만든 단순 표는 표로 재편집하며, 외부에서 지원 범위를 벗어나는 서식을 추가한 표는 셀 개체로 가져와 모양을 보존합니다. 셀 병합 UI는 제공하지 않습니다.

새 차트·다이어그램·WordArt·수식은 개별 도형·글자·선입니다. Office 차트 데이터, SmartArt 재배치, Office Math 개체와 동일한 기능은 아닙니다. 차트 입력은 단일 계열 최대 12항목입니다. 날짜 자동 갱신은 이 앱에서 수행하며 PPTX에는 그 시점의 날짜 텍스트를 저장합니다.

3D, OLE, 매크로, 영상·음악 재생, 화면 녹화, 확대/축소 전환은 이번 범위에 포함하지 않습니다. macOS에서 새 캡처 기능의 권한 흐름과 앱 실행은 검증하지 않았습니다.
