# Slide Studio 1.6.9

실제 작업 흐름에서 재현한 8개 편집·저장·발표 문제를 수정한 배포다.

- 복구용 자동 저장과 PPTX 파일 저장을 구분한다. 새 문서·파일 교체·닫기 전에 미저장 작업을 보호하며 저장 취소·실패는 저장 완료로 처리하지 않는다.
- 첫 텍스트·노트 입력에서 상단 실행 취소/다시 실행을 사용할 수 있다.
- 텍스트를 저장한 뒤 계속 입력해도 실행 취소가 저장 시점을 건너뛰지 않는다.
- 슬라이드 잘라내기가 원본을 제거하며 같은 문서 안의 이동은 내부 링크 ID와 노트를 보존한다.
- 저장 형식의 500장·장당 1,000개·문서 10,000개 한도를 넘는 추가를 미리 제한한다.
- PPTX 저장·재열기 후 표 머리글/줄무늬 옵션과 편집 동작을 보존한다.
- 빈 표 셀의 입력 글꼴·색·굵기·기울임·정렬·투명도를 보존한다.
- Mac 발표를 빠르게 종료·재시작할 때 이전 전체 화면 종료 이벤트가 새 발표를 취소하지 않도록 네이티브 전환을 순서대로 처리한다.

## 소스 검증

[실제 사용자 작업 흐름 검수](USER-WORKFLOW-QA-2026-10-22.md)에서 전체 334개 중 332개 통과, 환경 조건 2개 건너뜀, 실패 0개였다. 이후 추가한 네이티브 전환 상태 검사 5개도 통과했다. 합계 337개 통과이며 관련 브라우저 재실행은 중복 집계하지 않았다. 버전 변경 전 검수 소스는 `6f9ac12`다.

300장·500장 혼합 문서와 약 192MiB 공개 PPTX에서 편집·Undo/Redo·저장·재열기·반복 열기를 통과했다. 텍스트·노트·표 셀과 그림 SHA-256을 비교했다. 약 192MiB 파일은 열기 3.41초·저장 7.07초·다시 열기 4.05초였고 저장 중 최대 3.17초의 메인 스레드 작업은 남아 있다. 저사양 기기의 응답 속도와 모든 PowerPoint 조판 일치를 보장하지 않는다.

Windows 설치 앱 검사에서 발표 종료 뒤 전체 화면이 남는 문제를 추가로 재현했다. 네이티브 전체 화면 이벤트가 상태 조회값보다 먼저 전달되는 순서를 회귀 검사로 재현했으며, 다음 이벤트 루프에서 후속 전환을 처리하도록 수정했다. 새 재현 2개는 수정 전 실패·수정 후 통과했고 기존 전환 검사 5개도 통과했다. 기존 소스 검수와 합쳐 중복을 제외한 통과 수는 339개다. Windows 실제 배포 파일에서 같은 연속 발표·미디어·편집 시나리오를 다시 검사한다.

## 배포 검증 범위

Mac ARM64 ZIP, Windows x64 Setup/ZIP, Ubuntu 22.04/24.04 amd64 DEB를 만든다. Mac 번들은 별도 프로필에서 편집·PPTX/PDF·발표·판서·표·미디어와 실제 디스크 저장·재열기·닫기 보호를 검사한다. Windows와 Ubuntu 설치 앱도 설치·재설치·제거·사용자 자료 보존 및 기존 편집·표·발표·미디어를 검사한다. 네이티브 파일 선택 응답은 자동화에서 지정하고 실제 IPC와 파일 입출력을 사용한다.

검수 문서 교체 확인창의 Playwright 처리로 부모 창이 비활성화되는 자동화 현상을 피하기 위해, 알려진 검수용 문서 교체 문구에 한해서 응답한다. 실제 미저장 닫기 취소와 저장 후 정상 종료는 별도 보호 검사로 실행한다. 앱에 창 강제 활성화나 타이머 우회 기능을 추가하지 않았다.

Windows는 호스팅된 Windows Server, Ubuntu는 X11 환경이다. Windows/Linux 실제 키보드 IME 직접 타이핑·Wayland·종이 출력은 미검증이다. Mac은 Apple 미공증이고 Windows는 배포용 코드 미서명이다.

리토스 공유 URL과 고정 GitHub 다운로드 주소를 유지하며 Windows 설치 경고·Windows 우선 배치를 유지한다. 설치 파일 검증값과 실제 실행 결과는 최종 배포 확인 후 아래에 기록한다.

## 공개 배포 확인

[GitHub v1.6.9](https://github.com/beaur8-prog/slide-studio/releases/tag/v1.6.9)을 공개하고 [기존 리토스 다운로드·사용 안내](https://pink-photos-barrel-activation.trycloudflare.com/s/209727b046a226e48d2c00d344cf6facbd4bdb99d62595a6)를 동일한 URL·토큰·생성일·만료 설정으로 갱신했다. 서버 PID·포트와 터널 PID·주소를 유지했고 서버를 재시작하지 않았다. Windows 우선 배치와 다운로드 경고·‘추가 정보 → 실행’ 안내를 문서 맨 위에 유지했다.

검토한 1.6.9 본문과 삽입 그림 24개의 바이트를 공개 응답과 비교했다. PC·모바일에서 모든 그림이 로드되고 가로 넘침·브라우저 오류가 없음을 확인했다. 고정 latest/download 주소 5개에서 파일을 끝까지 다시 내려받아 바이트 수·SHA-256·GitHub digest와 v1.6.9 연결을 확인했다.

현재 버전만 남기는 정리 방침에 따라 이전 1.6.8의 GitHub 첨부 파일 5개와 이전 publication/리토스 그림 폴더를 삭제했다. 이전 태그·릴리스 설명과 현재 1.6.9 파일은 보존했다. 로컬 Mac 앱도 최종 실행 코드로 교체해 기본 제목 슬라이드 상태로 실행했다.
