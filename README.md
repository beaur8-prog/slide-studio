# Slide Studio

Mac, Windows와 Linux에서 독립적으로 실행하는 프레젠테이션 편집 앱입니다. PowerPoint의 공개 사용법에 나오는 리본, 슬라이드 목록, 개체 편집과 발표 흐름을 참고해 새로 구현했습니다. Microsoft PowerPoint 원본이나 원본 소스를 복원한 제품은 아닙니다.

**1.6.1**은 Sheet·Word와의 편집 가능한 표 복사·붙여넣기를 추가합니다. 세 앱을 Sheet 0.7.10 / Word 1.2.11 / Slide 1.6.1로 함께 업데이트하세요. [1.6.1 변경·검증 기록](qa/RELEASE-1.6.1.md)을 확인하세요.

1.6.0은 그룹·다중 선택 조작, 병합 표와 도형 내부 글자 편집, PPTX 서식 보존을 개선했습니다. 별도 발표자 창, 형광펜·판서 보관과 TTC/OTC 글꼴 모음도 지원합니다. 기존 글머리표·부분 서식·숫자 입력 수정도 포함합니다. [1.6.0 검증 기록](qa/RELEASE-1.6.0.md)을 확인하세요.

**Ctrl+K**로 명령과 슬라이드를 검색하고, **Ctrl+F1**로 리본을 접을 수 있습니다. 오른쪽 위 **서식** 버튼으로 서식 패널을 열고, 해/달 버튼으로 편집 화면의 밝기를 바꿉니다.

## 긴 텍스트 상자 설정

새 텍스트 상자는 기본적으로 내용에 맞춰 높이가 바뀌고, 기존 상자는 **서식 → 텍스트 → 내용에 맞춰 상자 높이 자동 조절**을 켜서 적용합니다. 높이를 직접 입력하거나 위·아래 조절점을 끌면 자동 높이가 해제됩니다. 가로쓰기·한 단 상자에서 지원하며, 슬라이드 밖으로 길어지면 글자 크기나 내용을 조절해야 합니다.

자동 높이 설정은 `.slide`와 PPTX에 보존합니다. 원본의 가로·한 단 `spAutoFit` 상자는 자동 높이로 읽으며, 그 밖의 고정 상자는 설정을 바꾸기 전까지 원래 높이를 유지합니다. 세로쓰기·다단 자동 높이와 동적 글자 축소는 제한됩니다. [변경 내용과 회귀 검사 범위](qa/TEXT-LAYOUT-2026-10-18.md)를 참고하세요.

## 다운로드와 실행

[최신 버전 다운로드](https://github.com/beaur8-prog/slide-studio/releases/latest)에서 운영체제에 맞는 설치 파일을 받으세요. 앱 안에 실행 환경이 포함되어 있으므로 **PowerPoint, Node.js, 인터넷 연결 없이** 사용할 수 있습니다.

| 운영체제 | 다운로드 | 실행 방법 |
| --- | --- | --- |
| macOS 12 이상 · Apple Silicon(M1 이후) | [Mac ARM64 ZIP](https://github.com/beaur8-prog/slide-studio/releases/latest/download/Slide-Studio-mac-arm64.zip) | ZIP을 풀고 Slide Studio.app을 응용 프로그램 폴더로 옮겨 실행 |
| Windows 10/11 · Intel/AMD 64비트 | [Windows Setup.exe](https://github.com/beaur8-prog/slide-studio/releases/latest/download/Slide-Studio-Setup-x64.exe) | 설치 마법사를 완료한 뒤 시작 메뉴의 Slide Studio 실행 |
| Ubuntu 22.04/24.04 · Intel/AMD 64비트 | [Linux amd64 DEB](https://github.com/beaur8-prog/slide-studio/releases/latest/download/Slide-Studio-linux-amd64.deb) | 아래 명령으로 설치한 뒤 앱 목록의 Slide Studio 실행 |

공개 배포 파일의 버전은 릴리스 페이지에서 확인하세요. 저장소의 소스 버전과 공개 릴리스 버전은 다를 수 있습니다.

다운로드 주소는 버전이 바뀌어도 동일합니다. 같은 주소를 사용하는 리토스 문서의 다운로드 버튼도 최신 공개 릴리스를 받으며, 파일 교체를 위해 공유 서버를 재시작할 필요가 없습니다.

Windows 설치판은 현재 사용자 계정의 `%LOCALAPPDATA%\Programs\Slide Studio`에 설치하고 시작 메뉴와 선택한 바탕화면 바로가기를 만듭니다. 업데이트 전에는 작업을 `.slide`로 저장하고 앱을 종료한 뒤 새 Setup을 실행하세요. Windows 설정의 설치된 앱에서 제거할 수 있으며 자동 저장 자료는 보존합니다. 기존 ZIP 배포본과 같은 `%APPDATA%\Slide Studio` 사용자 자료를 사용합니다.

Mac 빌드는 Apple 공증을 받지 않았고 Windows 빌드는 배포용 코드 서명이 없습니다. 따라서 다운로드·설치 또는 첫 실행 시 운영체제의 보안 경고가 표시되거나 실행이 제한될 수 있습니다. 앱 기능과 설치 검증 범위는 [1.6.0 검증 기록](qa/RELEASE-1.6.0.md)을 확인하세요. 실제 Windows/Linux 키보드 IME 직접 타이핑과 종이 출력은 미검증입니다. Intel Mac, Windows ARM 및 32비트용 패키지는 제공하지 않습니다.

### Windows 다운로드·설치 경고

- **다운로드할 때:** 브라우저에서 ‘위험한 파일’, ‘PC에 손상을 줄 수 있습니다’, ‘일반적으로 다운로드되지 않습니다’ 등의 경고가 나타날 수 있습니다. 현재 Windows 앱은 코드 서명이 없으며, 다운로드 평판이 충분하지 않은 파일에도 경고가 표시될 수 있습니다. 이 문서의 GitHub 다운로드 주소와 파일명 `Slide-Studio-Setup-x64.exe`를 확인하세요.
- **설치 파일을 실행할 때:** **‘Windows의 PC 보호’** 화면이 나오면 **추가 정보 → 실행**을 눌러 설치 마법사를 시작합니다. 이 문서에서 받은 파일인지 확인하고 설치를 진행하세요.
- 회사·기관 정책이나 Smart App Control로 실행이 차단된 경우에는 ‘실행’ 버튼이 없을 수 있습니다. 보안 설정을 끄지 말고 관리자에게 설치 허용 여부를 확인하세요. 악성코드 탐지 경고는 단순 미서명·평판 경고와 구분해야 합니다.

[Microsoft의 다운로드 경고 안내](https://support.microsoft.com/en-us/edge/how-can-smartscreen-help-protect-me-in-microsoft-edge)

Linux는 내려받은 파일이 있는 폴더에서 설치합니다. 설치·업데이트에는 관리자 권한과 한글 표시용 Noto CJK 글꼴 등 시스템 라이브러리를 받을 네트워크가 필요할 수 있습니다. 설치 후 앱은 일반 사용자 계정으로 실행하세요.

```sh
sudo apt install ./Slide-Studio-linux-amd64.deb
slide-studio
```

Linux 앱은 `/opt/slide-studio`에 설치하며 앱 목록에 기존 주황색 아이콘을 등록합니다. 제거는 `sudo apt remove slide-studio`를 사용합니다. 자동 저장 자료는 `$XDG_CONFIG_HOME/Slide Studio`(미설정 시 `~/.config/Slide Studio`)에 보관하고 제거 후에도 유지합니다. 업데이트 전 작업을 `.slide`로 저장하고 앱을 종료하세요. Linux 패키지는 별도 서명된 apt 저장소 배포가 아닙니다. [Linux 검증과 지원 범위](qa/LINUX-1.5.7.md)를 확인하세요. ARM, RPM, AppImage용 패키지는 제공하지 않습니다.

다운로드한 파일의 해시는 릴리스에 첨부된 `SHA256SUMS.txt`와 비교할 수 있습니다.

## 1.6.0의 주요 변경

그룹·범위 선택·회전·정렬/간격 배분, 외부 병합 표 편집, 표 인라인 입력·자동 행 높이·TSV 붙여넣기, 도형 내부 텍스트, 부분 링크, 그라데이션·외부 그림자·점선 보존을 추가했습니다. 슬라이드 다중 선택/우클릭/정렬 화면 드래그와 별도 발표자 창, 형광펜·판서 보관도 지원합니다. 수정 범위와 남은 호환성 제한은 [문제 수정 현황](powerpoint-issues/STATUS.md)에 기록합니다.

## 글머리표 목록

텍스트 상자를 선택하고 **홈 → • 글머리 기호**를 누릅니다. 목록 안에서 Enter를 누르면 다음 항목에 글머리표가 이어지고, Shift+Enter는 새 글머리표 없이 줄을 바꿉니다. 글머리표가 있는 줄과 없는 줄이 섞이면 버튼 한 번으로 모두 켜지고, 다시 누르면 모두 꺼집니다.

## 처음 사용하기

1. **파일 → 새 프레젠테이션**으로 시작하거나 **파일 → 파일 열기**에서 `.pptx` / `.slide` 파일을 엽니다.
2. **새 슬라이드**를 눌러 장을 추가하고, 왼쪽 목록을 끌어 순서를 바꿉니다.
3. 글자를 더블클릭해 입력합니다. 위쪽 도구에서 글꼴·크기·색을 바꾸고 **삽입**에서 도형과 이미지를 추가합니다.
4. **파일 → 프로젝트 저장**으로 편집용 `.slide` 파일을 보관합니다. 전달용 파일은 **PPTX 내보내기** 또는 **파일 → PDF 내보내기**로 만듭니다.
5. **발표하기**를 누르고 방향키 / Space / 마우스 휠로 이동합니다. 숫자 다음 Enter로 원하는 장에 이동하며, Esc로 편집 화면에 돌아옵니다.

편집 화면의 슬라이드 위에서 마우스 휠을 내리면 다음 장, 올리면 이전 장으로 이동합니다. 확대 상태에서는 먼저 화면을 스크롤한 뒤 가장자리에서 장을 넘깁니다. **Ctrl+휠**은 확대·축소하며, 왼쪽 목록은 자체적으로 스크롤됩니다.

큰 슬라이드 편집 영역 오른쪽의 스크롤바는 화면에 맞춤 상태에서도 항상 표시됩니다. 손잡이를 끌어 원하는 장으로 이동하거나 아래쪽 이전/다음 장 버튼을 사용할 수 있습니다. 확대 상태에서는 슬라이드 내부 위치도 조절하며, 스크롤바에 키보드 포커스를 두면 방향키·Page Up/Down·Home/End로 이동할 수 있습니다.

자동 저장은 현재 기기에만 남으며 기기 간 동기화를 하지 않습니다. 중요한 작업은 `.slide` 파일로도 저장하세요. 이전 문서는 왼쪽 위 로고 또는 **파일 → 내 프레젠테이션**에서 찾을 수 있습니다.

| 기능 | Mac | Windows / Linux |
| --- | --- | --- |
| 파일 열기 / 프로젝트 저장 | ⌘O / ⌘S | Ctrl+O / Ctrl+S |
| 실행 취소 / 다시 실행 | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Y |
| 새 슬라이드 / 복제 | ⌘M / ⌘D | Ctrl+M / Ctrl+D |
| 발표 / 인쇄 | ⌘Enter / ⌘P | Ctrl+Enter / Ctrl+P |

## 발표 포인터와 그리기

발표 중 우클릭 또는 F1로 발표 도구를 엽니다. **Ctrl/⌘+L**은 레이저, **Ctrl/⌘+P**는 펜, **Ctrl/⌘+A**는 화살표, **Ctrl/⌘+E**는 지우개입니다. 메뉴에서 색상과 굵기를 선택하며 Ctrl/⌘+Z로 그리기를 되돌리고 E로 현재 장의 표시를 지웁니다. 메뉴를 닫고 Esc를 누르면 발표가 끝납니다.

레이저·펜·지우개에서는 클릭으로 장을 넘기지 않습니다. 방향키·Space·휠로 이동하거나 화살표로 전환하세요. 그리기는 장별로 유지됩니다. 현재 소스에서는 발표 종료 후 **슬라이드에 보관** 또는 **판서 버리기**를 선택합니다. 보관한 판서는 편집 가능한 도형이 되어 저장·내보내기·인쇄에 포함됩니다. **Ctrl/⌘+H**는 형광펜입니다. 편집 화면의 Ctrl/⌘+P는 인쇄입니다.

## 소스에서 실행

Node.js 22 이상과 npm을 준비한 뒤 다음 명령을 사용합니다.

```sh
git clone https://github.com/beaur8-prog/slide-studio.git
cd slide-studio
npm ci
npm run build
npm start
```

브라우저에서 개발하려면 `npm run dev`를 실행하고 http://127.0.0.1:5190 을 엽니다. 데스크톱 앱 개발 모드는 개발 서버를 켠 뒤 `npm run desktop`으로 실행합니다.

## 편집 기능

- 제목, 본문, 두 단, 빈 화면 레이아웃으로 슬라이드를 추가합니다. 목록에서 끌어서 순서를 바꾸고 복제·삭제할 수 있습니다.
- 텍스트를 더블클릭하거나 선택 후 Enter를 눌러 편집합니다. 글꼴, 크기, 굵게, 기울임, 밑줄, 정렬과 색상을 변경할 수 있습니다.
- 이미지와 기본 도형을 삽입하고 마우스로 이동·크기 조절합니다. 오른쪽 패널에서 위치, 크기, 회전과 불투명도를 정확하게 지정합니다.
- **삽입 → 표**에서 최대 100행 × 50열의 표를 만듭니다. 셀 선택 후 Enter/F2/타이핑으로 직접 입력하고 Tab/Shift+Tab으로 이동합니다. 선택 셀 편집 창에서 병합/나누기·행/열 추가와 삭제·서식을 적용합니다. 새 표는 내용에 맞춰 행 높이를 늘리고, 가져온 표는 원본 높이를 기본 보존합니다. 표 편집 창의 자동 행 높이 옵션으로 변경합니다.
- 슬라이드 위의 표 안을 **드래그**하거나 **Shift+클릭**하면 직사각형 셀 범위를 선택합니다. **Delete**는 선택한 셀 내용만 지우고 **선택 셀 편집**은 해당 범위에 서식을 적용합니다. Ctrl+A는 모든 셀 선택, Shift+방향키는 범위 확장, Esc는 셀 선택 해제입니다. 표 전체는 위쪽 **표 이동** 핸들이나 가장자리로 옮기며, 모서리 핸들로 크기를 조절합니다. 개별 셀 서식은 프로젝트와 PPTX에 보존됩니다.
- 표의 **셀 사이 경계선**에 마우스를 올리면 크기 조절 커서와 파란 선이 나타납니다. 세로 경계는 좌우로, 가로 경계는 위아래로 드래그하세요. 표 전체 크기를 유지하면서 인접한 두 열·행의 크기를 조절합니다. **Esc**로 드래그를 취소하고 **Ctrl+Z**로 조절 전 크기로 되돌릴 수 있습니다. 경계선에 Tab으로 포커스를 두면 방향키로도 조절하며, Shift를 함께 누르면 10단위씩 조절합니다. 바뀐 크기는 프로젝트와 PPTX에 보존됩니다.
- **삽입 → 차트**는 세로 막대·가로 막대·꺾은선·원형 4종과 CSV/탭 구분 데이터 입력을 지원합니다. 다이어그램 4종, 아이콘 16종, 추가 도형 14종, WordArt·분수·수식·기호도 삽입할 수 있습니다. 차트와 다이어그램은 개별 도형·글자로 만들어지며 원본 데이터 편집 창과 자동 재배치 기능은 없습니다.
- **사진 앨범**은 최대 20장의 사진을 선택해 슬라이드마다 1·2·4장씩 배치합니다. **스크린샷**은 데스크톱에서 창·화면을 선택해 캡처하며, 브라우저에서는 캡처 이미지 파일을 선택합니다.
- **링크**는 개체에 웹 주소 또는 문서 안의 슬라이드를 연결합니다. 발표 중 클릭하거나 Tab으로 선택 후 Enter로 이동합니다. **날짜 및 시간 / 슬라이드 번호 / 바닥글**은 현재 장 또는 전체 장에 적용하고 번호는 순서를 바꾸면 갱신됩니다.
- 도형·텍스트를 **우클릭**하면 개체 편집 메뉴를 엽니다. 선택한 여러 개체 중 하나를 우클릭하면 다중 선택을 유지하고, 다른 개체를 우클릭하면 그 개체를 선택합니다. **Shift+F10**으로도 열고 방향키·Enter·Esc로 조작합니다. 텍스트 입력 중에는 선택한 글자와 커서 위치를 유지한 채 텍스트 편집 메뉴를 엽니다. 복사·잘라내기·삭제는 선택한 글자에 적용되며, **텍스트 상자 메뉴**를 누르면 개체 전체 메뉴로 전환합니다.
- 글자를 드래그해 일부를 선택한 뒤 **홈 → 글자 색(A)** 또는 **우클릭 → 글자 색**을 엽니다. 선택한 글자 표시가 유지되며, 색상 견본이나 코드를 고른 뒤 **적용**해야 색이 바뀝니다. **취소 / Esc**는 원래 선택으로 돌아갑니다. 글자 선택 없이 텍스트 상자만 선택했다면 상자 전체에 적용합니다. 부분 색상과 기존 서식은 .slide와 PPTX에 보존됩니다.
- Shift로 여러 개체를 선택합니다. 복사·붙여넣기, 복제, 레이어 순서, 잠금, 정렬, 눈금 맞춤과 안내선을 지원합니다.
- 테마와 배경, 16:9 / 4:3 비율을 변경합니다. 발표자 노트와 페이드 전환을 설정합니다.
- 발표를 시작하면 자동으로 전체 화면으로 전환합니다. 클릭·방향키·Space로 이동하고 숫자 + Enter로 원하는 장에 바로 이동합니다. 영문 입력 상태에서 B로 검은 화면을 켠 뒤 탐색하면 같은 장이 먼저 다시 표시됩니다. Esc로 중단하면 현재 발표 장을 편집하며, 마지막 장 뒤에는 종료 안내가 나옵니다.
- **슬라이드 쇼 → 슬라이드 숨기기**로 일반 발표에서 제외할 장을 지정합니다. 축소판 번호에 취소선이 표시되며 PPTX와 프로젝트 파일에 숨김 설정을 보존합니다. 현재 장부터 시작하거나 번호로 직접 이동하면 숨긴 장도 볼 수 있습니다.
- 실행 취소와 다시 실행을 지원합니다. 변경 내용은 이 기기의 IndexedDB에 자동 저장합니다. 로고 또는 파일 메뉴의 **내 프레젠테이션**에서 이전 문서를 열 수 있습니다.

## 파일

- **프로젝트 저장 (.slide)**: 앱의 편집 상태를 온전히 보관하는 JSON 형식입니다. 백업과 작업 이어가기에 사용합니다.
- **PowerPoint (.pptx)**: 문단·부분별 글자 서식, 도형·이미지, 새로 만든 표를 편집 가능한 개체로 내보냅니다. 신규 표는 PowerPoint의 실제 표이며, 슬라이드 번호는 자동 번호 필드입니다. 웹·슬라이드 링크, 슬라이드 크기, 노트, 단순 페이드 전환을 포함합니다.
- **PPTX 열기**: 텍스트·도형·이미지·노트와 테마·레이아웃 상속을 가져옵니다. 문단 간격, 한글 세로쓰기, 표의 셀과 병합 영역, TIFF 이미지, 이미지 자르기, 지원하는 자유형 도형과 마스터 장식도 보존합니다. 현재 소스는 일반/병합 표를 네이티브 표로 가져오며, 100행×50열을 넘거나 손상된 표는 셀 개체로 가져올 수 있습니다. 호환되지 않는 항목은 가져오기 후 안내합니다.
- **PDF 내보내기**: 데스크톱 앱의 파일 메뉴에서 현재 모든 슬라이드를 PDF로 저장합니다. 브라우저에서는 인쇄 대화상자의 PDF 저장을 사용합니다.
- **인쇄**: 프린터를 운영체제에 등록한 뒤 **파일 → 인쇄** 또는 **⌘P / Ctrl+P**를 사용합니다. 슬라이드 한 장을 한 페이지로 출력하며 편집 도구와 발표자 노트는 제외합니다. 프린터가 없는 Mac에서는 인쇄 창이 열리지 않으므로 **PDF 내보내기**를 사용하세요. 브라우저에서는 파일 메뉴로 브라우저 인쇄 창을 엽니다.

외부 PPTX의 네이티브 차트 데이터 가져오기, 3D 모델, OLE 개체, 매크로, 영상·음악 재생, 화면 녹화와 복잡한 애니메이션은 지원하지 않습니다. 새 차트는 단일 데이터 계열 최대 12항목을 사용합니다. 수식은 편집 가능한 텍스트·선이며 Office 수식 엔진을 사용하지 않습니다. SmartArt는 파일 안에 저장된 도형 배치가 있는 경우 개별 도형으로 가져오며 자동 재배치는 지원하지 않습니다. Calibri 대체용 Carlito와 나눔바른고딕 글꼴을 앱에 포함합니다. 원본의 한영 글꼴 구분·자간·커닝·탭과 줄바꿈 설정을 보존하며, 원본 글꼴이 설치되어 있으면 우선 사용합니다. Office 전용 폴더의 Calibri도 자동으로 확인하며, **파일 → 원본 글꼴 추가**에서 TTF·OTF·TTC·OTC 파일을 기기에 저장해 재실행 후에도 사용할 수 있습니다. 일반·굵게·기울임 파일은 각각 추가합니다. 없는 상용 글꼴은 대체되므로 일부 모양·줄바꿈 차이가 남습니다. [글꼴 처리와 한계](FONT_NOTES.md)를 참고하세요. 복잡한 그룹 변환·효과와 일부 벡터 형식도 제한됩니다. 세부 호환 범위는 [IO_NOTES.md](IO_NOTES.md)를 참고하세요.

파일 입력 상한은 256 MiB이며, 압축 해제 크기·이미지·개체 수에는 별도 제한이 있습니다. 공개 PPTX 8개, 총 499장을 열고 저장 왕복을 검사했습니다. 검사 범위와 재현 방법은 [검증 안내](qa/README.md)와 [1.6.0 검증 기록](qa/RELEASE-1.6.0.md)을 확인하세요.

발표자 노트는 편집 화면에서 작성하며 발표 화면에는 표시하지 않습니다. 현재 소스에서는 **슬라이드 쇼 → 발표자 보기**로 별도 창에 현재/다음 슬라이드와 비공개 노트를 표시합니다. 그 창을 발표자가 보는 모니터로 옮길 수 있습니다.

PPTX 가져오기의 자동 번호, 빈 줄 높이, 기본 줄 간격과 번호 들여쓰기를 보정했습니다.
이전에 가져와 저장한 문서의 잘못된 번호는 원본 PPTX를 다시 열어 적용하세요.
후속 수정의 검증 결과는 [Windows 비교 기록](POWERPOINT-ANALYSIS.md#문단-레이아웃-후속-수정)에 있습니다.

## 검증과 빌드

```sh
python3 scripts/fetch-qa-samples.py  # 공개 PPTX 회귀 검사에 필요한 자료
npm run build
npm test
npm run package:mac  # macOS에서 실행
npm run package:win  # Windows x64 Setup.exe와 ZIP 생성, macOS에서도 가능
npm run package:linux  # Linux amd64 DEB 생성, macOS/Linux + Python 3
```

테스트는 설치된 Google Chrome을 사용합니다. PPTX 왕복 변환, 슬라이드 순서, 테마·레이아웃 상속, 한글 조합·저장·실행 취소, 300장 편집 성능, 잘못된 프로젝트 입력과 압축 파일 경계 조건을 확인합니다. 공개 자료 회귀 검사는 `python3 scripts/fetch-qa-samples.py`로 받은 샘플이 필요하며, 배포용 자산 검사는 먼저 빌드해야 합니다. `npm run package` / `npm run package:mac`은 Mac 앱 번들과 ZIP을 만듭니다. `npm run package:win`은 공식 Electron Windows x64 런타임의 SHA-256을 검증한 뒤 PC용 ZIP과 NSIS 설치 프로그램을 만듭니다. NSIS와 7-Zip이 필요하며 Mac에서는 `brew install makensis sevenzip`으로 준비합니다. 기존 ZIP으로 설치 파일만 다시 만들려면 `npm run package:win:setup`을 사용합니다. 앱은 로컬 임시 서명을 사용하며 Apple 공증 배포본은 아닙니다.

macOS의 동기화 폴더가 앱 번들에 Finder 메타데이터를 추가할 수 있으므로 배포에는 서명 검증을 마친 임시 빌드에서 생성한 ZIP을 사용합니다. 패키징과 네이티브 연동은 [DESKTOP.md](DESKTOP.md)에 설명했습니다.

## 구현

React + TypeScript 편집기, Electron 데스크톱 셸, IndexedDB 자동 저장, JSZip 기반 PPTX 읽기와 PptxGenJS 기반 PPTX 쓰기를 사용합니다. 원본 PowerPoint 바이너리나 Microsoft 리소스를 앱에 포함하지 않습니다.

- `src/App.tsx`: 편집 상태, 리본, 슬라이드 목록, 서식 패널, 발표 모드
- `src/SlideCanvas.tsx`: 개체 선택, 이동, 크기 조절, 텍스트 직접 편집
- `src/model.ts`: 문서 모델 생성, 레이아웃, 예제와 테마
- `src/io.ts`: 프로젝트 검증과 PPTX 읽기·쓰기
- `src/storage.ts`: 기기 내 자동 저장과 문서 목록
- `electron/`: 로컬 파일 대화상자, PDF, 앱 메뉴

## Studio 앱 간 표 복사 (1.6.1)

Sheet Studio 0.7.10과 Word Studio 1.2.11의 표를 홈 붙여넣기 또는 Ctrl+V/⌘V로 받아 셀을 편집할 수 있습니다. 표 하나나 셀 범위를 복사하면 두 앱으로도 보낼 수 있습니다. HTML의 10 MB 한도는 한글을 포함한 UTF-8 바이트로 계산합니다. [사용법·교환 형식·각 앱 구현 및 제한](https://github.com/beaur8-prog/sheet-studio/blob/main/docs/STUDIO-CLIPBOARD.md)을 확인하세요.

표와 미리보기 이미지가 함께 들어오면 편집 가능한 표를 우선합니다. 브라우저 홈 붙여넣기는 같은 클립보드 항목의 HTML·TSV만 사용하며, 읽는 동안 문서·슬라이드·선택·입력 위치가 바뀌면 취소합니다. [검증 범위와 사용 순서](qa/STUDIO-CLIPBOARD-1.6.1.md)를 참고하세요.
