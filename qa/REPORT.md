# Slide Studio 글꼴·줄바꿈 개선 검증

검사일: 2026-10-17. 대상: **1.2.1**. [이전 1.2.0 결과](REPORT-1.2.0.md).

글꼴 선택, 글자 폭·줄 높이, 한영 혼용과 원본 자간을 보완했습니다. `/Applications/Slide Studio.app`을 1.2.1로 업데이트했으며 **앱을 다시 열고 원본 PPTX를 다시 불러오면** 새 가져오기 규칙이 적용됩니다.

## 달라진 점

- 원본 글꼴이 설치돼 있으면 우선 사용합니다. 나눔바른고딕 Regular·Bold·Light의 공식 배포본을 앱에 포함해 오프라인에서도 사용합니다.
- Calibri 대체 글꼴의 세로 측정값을 보정하고, Calibri Light에는 별도 폭 보정을 적용했습니다. 원본 글꼴 이름과 명목상 글자 크기는 프로젝트와 PPTX에 유지합니다.
- 한 문장에 섞인 영문·한글 글꼴을 각각 상속하고 표시합니다. 일본어·중국어·한국어 테마 글꼴도 문자의 종류와 언어를 따릅니다.
- 원본 자간, 커닝 기준 크기, 탭 간격, 문단 줄바꿈 설정을 읽고 저장합니다. 영문 단어 중간 줄바꿈 설정이 긴 한글의 줄바꿈을 막지 않도록 분리했습니다.
- 그룹의 확대 비율이 글자에 중복 적용되는 문제를 수정했습니다. CMU 3의 그림 설명은 원본 XML/PDF의 20pt로 표시됩니다. 기존에는 약 28.36pt였습니다.

글꼴 출처·라이선스·구현 범위: [FONT_NOTES.md](../FONT_NOTES.md).

## 원본과 비교한 결과

CMU lecture 3, 34쪽의 `until min resolution reached` 문장은 원본에서 한 줄인데 기존 앱에서는 두 줄이었습니다.

| 측정 | 폭 |
| --- | ---: |
| 원본 PDF | 301.99px |
| 1.2.0 대체 글꼴 | 305.52px |
| 1.2.1 대체 글꼴 | 301.84px |
| 원본 텍스트 상자의 내부 폭 | 302.74px |

현재는 원본 상자 안에 **한 줄**로 표시됩니다. [이전 화면](results/layout-final/cmu-lecture-3-slide-034.png) · [현재 화면](results/fonts-verified/font-cmu3-slide34.png) · [원본 PDF 화면](results/final/reference-cmu-3-034.png).

보정에 사용하지 않은 CMU 2·3의 **다른 6쪽, 문장 27개**에서도 비교했습니다. 문장별 폭 오차의 평균은 **1.24% → 0.23%**였습니다. Calibri Light, 10문자 이상, 단일 서식의 추출 가능 문장을 대상으로 했고 PDF 좌표의 반올림 오차가 포함됩니다. 모든 글꼴·모든 슬라이드의 오차율이라는 뜻은 아닙니다. [측정 기록](results/fonts-after/font-metrics.json) · [비교 문장](results/fonts-before/holdout-lines.json).

## 전체 자료 재검사

기존 공개 PPTX **5개, 465장**을 다시 열고 전체 텍스트 경계를 자동 검사했습니다. 대표 화면 **35장**을 육안 확인했습니다. 465장을 모두 원본 PDF와 한 장씩 대조한 것은 아닙니다.

- 잘림 설정이 있는 상자에서 넘치는 텍스트 후보: **0개**.
- 화면 밖 텍스트 경계 후보: **0개**.
- 서로 겹치는 텍스트 줄 경계 후보: **0쌍**.
- 상자를 넘어 표시되는 텍스트 후보: **51개**. 원본의 넘침 허용 설정에 따라 표시되는 경우가 포함되며, 결함 수와 같지 않습니다.
- 도형 단위의 텍스트 상자 겹침 후보: **103쌍**. 상자끼리 겹치더라도 글자끼리 겹친다는 의미는 아닙니다.
- JavaScript 예외: **0건**. 5개 모두 PPTX 내보내기·다시 가져오기에서 슬라이드 수, 슬라이드별 텍스트, 이미지 수를 보존했습니다.

검사 도구는 탭의 빈 공간이 줄 끝에서 화면 밖으로 측정되는 경우를 제외하도록 보완했습니다. 글꼴 경계는 실제 획보다 크기 때문에 이 수치를 완전한 시각적 동일성의 증거로 해석해서는 안 됩니다. [원시 결과](results/fonts-verified/corpus.json) · [집계](results/fonts-verified/summary.json).

## 속도와 입력·저장

최종 실행은 파일마다 1회입니다. 동일 기기의 개발 서버와 격리 Chrome에서 파일 입력, UI 표시와 자동 저장을 측정했으며, 사전 파싱·캐시의 영향이 있습니다. 네이티브 앱의 완전한 최초 실행 시간은 아닙니다.

| 자료 | 크기 | 장수 | 편집 화면 표시 | 자동 저장 완료 |
| --- | ---: | ---: | ---: | ---: |
| CMU 1 | 191.80 MiB | 70 | 1.94초 | 1.99초 |
| CMU 2 | 11.72 MiB | 116 | 1.59초 | 2.17초 |
| CMU 3 | 48.94 MiB | 151 | 1.16초 | 1.63초 |
| CMU 4 | 14.84 MiB | 106 | 0.76초 | 1.20초 |
| 한글 자료 | 1.89 MiB | 22 | 0.28초 | 0.75초 |

`npm test` **31개 모두 통과**(56.8초). 새 글꼴 검사 5개, 기존 레이아웃·입력·파일 검사, 배포용 자산 검사를 포함합니다. 실제 적용된 글꼴 이름을 브라우저에서 확인해 나눔바른고딕 사용을 검증했습니다. [검사 기록](results/fonts-verified/test-summary.json).

한글 조합 입력, 한영 혼용, 실행 취소·다시 실행, 자동 저장 후 재열기와 프로젝트/PPTX 왕복 검사가 통과했습니다. 300장 합성 문서는 재열기 1.464초, 자동 10키 입력 0.241초, 편집 종료부터 저장 완료까지 0.885초였습니다. [입력 화면](results/fonts-verified/korean-composition.png) · [측정값](results/fonts-verified/300-slide-timings.json).

## 설치와 남은 차이

TypeScript·프로덕션 빌드·패키징을 완료했습니다. 설치된 1.2.1 앱의 엄격한 서명 검증이 통과했고, 앱 데이터 및 포함된 글꼴의 해시가 검증된 빌드와 일치합니다. [배포 ZIP](../release/Slide-Studio-mac-arm64.zip).

Calibri Light의 획 모양·굵기는 대체 글꼴과 차이가 남습니다. HY나무M, HY바다M, Sandoll 등 설치되지 않은 상용 글꼴도 대체됩니다. 사용자 지정 탭 위치, 고급 글머리표·금칙 처리와 PowerPoint 고유의 조판까지 모두 재현한 것은 아닙니다. 내보낸 PPTX에는 글꼴 이름만 기록하며 글꼴 파일을 포함하지 않습니다.

Mac 잠금 상태가 유지돼 이번 버전의 네이티브 창 재실행, 실제 프린터 출력, macOS 키보드 IME의 현장 동작은 다시 확인하지 못했습니다. 개발·배포 자산은 격리 Chrome에서 검증했습니다.
