# Slide Studio 1.6.3

2026-10-20. 삼각형 꼭짓점 편집과 GIF 정지 미리보기를 포함한다.

## 변경

- 삼각형을 선택하면 세 꼭짓점에 노란 조절점이 표시된다. 마우스 드래그 또는 방향키로 점을 이동한다. 회전·뒤집기·배율을 반영하며 한 드래그를 한 번의 실행 취소로 되돌린다. 흰색 핸들은 도형 전체 크기를 조절한다.
- 원본 PPTX의 삼각형 조절값과 직선 점 편집 경로를 실제 좌표로 읽고, 편집한 경로를 프로젝트/PPTX에 보존한다. 텍스트가 있는 사용자 도형을 PPTX로 저장하면 사각형으로 바뀌던 문제를 수정했다. 편집한 도형은 자유형 경로로 저장하므로 PowerPoint 프리셋의 원래 노란 조절점 정보는 복원하지 않는다.
- GIF는 편집·축소판·사진 앨범·발표자 미리보기·PDF·인쇄에서 첫 프레임만 표시한다. 현재 발표 장에서만 원본을 재생하며 화면 가리기·다른 장 이동·종료 시 중단한다. 원본 프레임·투명도·반복 설정과 저장/내보내기 데이터는 유지한다.
- 미리보기는 한 프레임짜리 GIF로 만들고 메모리에서 캐시한다. 숨겨진 원본 애니메이션을 계속 재생하지 않는다. 동영상의 미리보기 자체가 GIF인 경우도 정지한다. MP4/WebM 재생 설정은 유지한다.

## 검증 범위

수정 단계에서 관련 32개 검사와 Mac 패키지의 실제 GIF/H.264 MP4/VP8 WebM 재생을 확인했다. 배포 전에는 전체 회귀 검사, 네 패키지의 버전·구성·동일 실행 코드·SHA-256 검사와 Windows/Ubuntu 설치 앱 검사를 추가한다. 최종 결과는 완료 후 기록한다.

GIF 40개가 있는 자료의 편집·축소판·인쇄와 현재 발표 장의 이미지 소스를 검사한다. 투명도·로컬 팔레트·인터레이스·부분 이미지 위치, 잘린 GIF, 저장 후 원본 바이트와 실제 발표 프레임 변화를 확인한다. CPU/GPU·배터리 절감률을 수치로 측정한 검사는 아니다.

Mac 미공증·Windows 미서명 배포다. 다운로드 경고와 **Windows의 PC 보호 → 추가 정보 → 실행** 안내를 다운로드 문서에 유지한다. 일반 PPTX용 배포이며 별도로 추가된 Windows DRM 가져오기는 포함하지 않는다. 모든 상용 글꼴·PowerPoint 효과/조판의 완전 일치, 복잡한 곡선 점 편집, 외부 연결 미디어·오디오·복잡한 영상 타이밍, 실제 키보드 IME 직접 입력·Wayland·종이 출력은 이번 검증 범위에 포함하지 않는다.

기존 [리토스 다운로드 문서](https://pink-photos-barrel-activation.trycloudflare.com/s/209727b046a226e48d2c00d344cf6facbd4bdb99d62595a6)는 같은 공유본으로 갱신한다. 문서와 바이너리의 고정 다운로드 주소를 유지한다.

## 배포 전 소스 검사

전체 285개 중 **283개 통과·환경 조건에 따른 2개 제외**, 실패와 불안정 재시도는 없었다. 도형 187종·조절값 300개의 1,800개 조건, 삼각형 꼭짓점 편집, GIF 40개 자료의 정지 미리보기, 원본 바이트와 실제 발표 재생, 기존 표/그룹/클립보드/글꼴/부분 서식/저장·발표 검사를 포함한다. 결과는 `qa/results/release-1.6.3/full-regression.json`과 `final-regression-summary.json`에 있다.
