# Slide Studio 1.4.2 검증 기록

2026-10-18(KST), macOS arm64에서 검사했습니다. 이 파일은 **슬라이드 쇼 휠 수정까지 포함한 1.4.2 보완 배포**입니다. 초기 1.4.2를 받았다면 같은 주소에서 다시 내려받아 교체해야 합니다. 버전 번호는 1.4.2를 유지합니다.

## 원인과 수정

편집 화면과 달리 초기 1.4.2의 슬라이드 쇼에는 휠 입력을 60px까지 모으고 전환 후 350ms 동안 추가 입력을 버리는 기준이 남아 있었습니다. 이제 두 화면 모두 12px부터 반응하며 고정 대기 시간을 사용하지 않습니다. 80ms보다 긴 입력 간격이나 방향 반전을 새 동작으로 보고, 연속된 관성 입력은 한 번만 처리합니다.

확대 상태의 내부 스크롤, Ctrl/Meta+휠 확대, 왼쪽 목록과 텍스트 편집 보호를 유지합니다. 슬라이드 쇼는 숨긴 장을 건너뛰며, 검은 화면을 휠로 복원한 직후 같은 관성 입력으로 다음 장까지 넘어가지 않습니다. 마지막 장 뒤의 종료 안내도 같은 입력의 꼬리 때문에 곧바로 닫히지 않습니다.

초기 1.4.2에서 **슬라이드 쇼에 20px 입력 한 번을 보내도 1번 장에 머무는 것**을 새 회귀 검사로 먼저 재현했습니다. 수정 후 첫 입력에 2번 장으로 이동하고 120ms 간격의 다음 입력은 3번·4번으로 이동했습니다. 방향 반전, 줄 단위 입력, 종료와 재시작도 통과했습니다.

편집 화면의 이전 20px / 120ms 비교에서는 1.4.1의 첫 두 입력이 1번 장에 머물고 세 번째에 2번 장으로 이동했으며, 편집 수정본은 첫 입력부터 한 장씩 이동했습니다. 이 결과는 해당 입력 크기에서의 측정이며 모든 물리 마우스와 드라이버 설정의 동일한 반응을 보장하지는 않습니다.

## 자동 검사

프로덕션 빌드가 통과했고 전체 Playwright 검사 **92개 통과, 2개 제외, 실패·불안정 검사 0개**를 확인했습니다(151.0초). 제외 항목은 실제 Windows 창 크기와 Office 글꼴 캐시를 요구합니다.

- 편집 화면과 슬라이드 쇼의 작은 휠 입력, 빠른 별도 조작, 방향 반전, 줄 단위 입력
- 작은 떨림과 600ms의 연속 관성 입력, 한 번의 입력으로 여러 장이 넘어가지 않는지 확인
- 숨긴 장 건너뛰기, 검은 화면 복원, 마지막 장 종료 안내와 역방향 복귀, 다음 조작으로 종료 및 발표 재시작
- 기존 확대 화면 스크롤, Ctrl+휠, 목록·스크롤바, 편집·발표 격리·파일·한글 조합 이벤트 검사

연속 입력 검사는 각 입력 사이의 검증 대기가 새 동작을 만들지 않도록 30ms 간격으로 명시했습니다. 1.4.1의 공개 PPTX 5개·465장 전체 검사와 별도 메모리 계측은 이번에 반복하지 않았습니다. 해당 수치와 이전 Mac 저장·내보내기 확인은 [1.4.1 검증 이력](RELEASE-1.4.1.md)에 있습니다.

## 실제 Mac 앱

배포 ZIP을 새 임시 폴더에 풀어 서명을 검사한 뒤 초기 1.4.2 앱과 사용자 프로필을 백업하고 `/Applications/Slide Studio.app`을 보완 빌드로 교체했습니다. 설치한 ASAR은 두 배포 ZIP과 같습니다.

기존 5장짜리 문서가 열렸고 저장 완료 표시를 확인했습니다. 네이티브 전체 화면 슬라이드 쇼에서 작은 스크롤 동작(0.1페이지)으로 1→2→3→2장 이동을 확인했습니다. End로 마지막 장에 간 뒤 작은 휠 조작은 종료 안내를 표시했고, 같은 조작의 연속 이벤트로 바로 닫히지 않았습니다. 역방향 휠로 마지막 장을 복원하고 Esc로 편집 화면에 돌아왔습니다.

편집 화면의 작은 휠 입력으로 1→2→1장 이동도 확인했습니다. 문서 내용은 편집하지 않았으며 원래 보고 있던 1번 장과 화면 맞춤 86% 상태로 돌려놓았습니다. 실제 물리 마우스의 한 클릭을 계측한 검사는 아니며, 정확한 20px 입력은 별도 자동 검사입니다.

## 패키지

두 ZIP의 전체 CRC32 검사와 프로덕션 ASAR 검사를 통과했습니다. 버전 매니페스트는 1.4.2이며 자산·Electron 셸 23개 파일이 작업 사본과 바이트 단위로 같습니다. 공통 ASAR SHA-256은 `0c59f1aca112ea130c971c76240b9a4dd0e802ae0dc31cf9e5cfe52da41fbce7`입니다. Mac 추출본과 설치본은 strict 코드 서명 검사를 통과했고, Windows는 공식 Electron 42.11.15의 체크섬·PE x64 구조·필수 파일·메타데이터와 원본 코드 섹션을 검증했습니다.

## 검증 범위

이번 Windows ZIP의 실제 Windows 실행은 수행하지 않았습니다. Mac은 ad-hoc 서명이며 공증하지 않았고 Windows는 배포 서명이 없습니다. 실제 OS IME 조합 입력과 종이 출력은 미검증입니다.

이번 로컬 증거는 `qa/results/release-1.4.2-slideshow/`, 문서 갱신 증거는 `qa/results/release-1.4.2-slideshow-document/`에 있습니다. 초기 1.4.2와 편집 휠 비교의 이력은 `qa/results/release-1.4.2/` 및 `qa/results/wheel-response/`에 남겼습니다. 생성 결과와 사용자 문서·공유 설정은 Git에 포함하지 않습니다.
