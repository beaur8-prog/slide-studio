# Slide Studio 1.4.0 배포 검증

2026-10-17, macOS arm64에서 검사했다. PC에서 반영한 `3af82af`·`49d9c16`·`3b15e73`을 포함해 Mac ARM64와 Windows x64 배포 ZIP을 만들었다. 다운로드와 사용법은 [README](../README.md), 배포 파일은 [1.4.0 릴리스](https://github.com/beaur8-prog/slide-studio/releases/tag/v1.4.0)에 있다.

## 포함된 변경

- 제목 표시줄·리본·명령 검색·서식 패널·밝은/어두운 편집 화면.
- 슬라이드 목록과 편집 영역의 독립 스크롤, 확대 상태의 탐색.
- 표 줄 간격, 둥근 도형의 텍스트 영역·도넛 두께, 양끝 선 장식과 한글 문장부호 줄바꿈 보정.
- 기존 Windows Office 캐시의 Arial Nova Light를 선택적으로 사용. 글꼴 파일은 배포하지 않는다.
- 발표 시작 시 자동 전체 화면, Esc로 편집 화면 복귀. 발표 화면의 떠 있는 도구 모음은 제거했다.

## 자동 검사와 Mac 글꼴 차이

`npm run build`를 통과했고 전체 `npm test` 결과는 **58개 통과, 2개 제외, 실패·불안정 재시도 0개**, 79.3초다. 제외된 검사는 Windows 실제 창의 전체 화면 경계와 기존 Office 캐시 글꼴을 요구한다.

초기 실행에서는 Windows 맑은 고딕을 전제로 한 두 검사가 실패했다. 문장부호 검사의 Canvas 측정을 실제 렌더러와 동일한 글꼴 대체 순서로 바꾸었다. 동신대학교 10번 슬라이드는 원본 글꼴이 있을 때 정확한 줄바꿈을 비교하고, 모든 환경에서 두 줄 유지·내용 보존·상자 내 배치를 검사하도록 보완했다. 이 검사를 통과시키기 위해 앱의 글꼴이나 글자 크기를 변경하지 않았다. Mac 대체 글꼴의 정확한 줄바꿈 위치는 Windows 원본과 여전히 다를 수 있다.

300장 문서 검사는 재열기 1.444초, 자동 키 입력 10회 0.174초, 편집 종료 후 저장 표시까지 0.863초였다. 한 번의 macOS Chrome 실행 측정이며 다른 기기의 속도를 보장하지 않는다.

35개 대표 화면을 생성했다. 이번 실행에서는 CMU 3의 34번, CMU 4의 16번, 동신대학교 8·21번 화면을 육안 확인했다. 기존 Windows 원본 비교 범위는 [PowerPoint 관찰 기록](../POWERPOINT-ANALYSIS.md)에 있다.

## 실제 Mac 배포 앱

생성한 ZIP을 임시 폴더에 풀어 서명을 검사하고 `/Applications/Slide Studio.app`에 설치했다. 이전 앱과 사용자 프로필은 로컬에 백업했다. 설치된 앱은 1.4.0이며 ASAR 해시는 배포 ZIP과 같다.

- 기존 문서가 열리고 자동 저장 상태를 유지했다.
- 발표가 네이티브 전체 화면으로 전환하고, 방향키로 다음 장에 이동했으며 Esc로 일반 편집 창에 돌아왔다.
- 별도 검증 문서에서 한글·영문·숫자와 두 줄 텍스트를 붙여넣어 편집하고 실행 취소했다. 실제 OS 입력기의 조합 입력 검사는 아니다.
- 네이티브 저장 대화상자로 `.slide`를 저장했다. 원본 검증 프로젝트와 저장한 JSON은 동일하며 4장·28개 개체를 포함한다.
- 네이티브 대화상자로 PPTX를 내보내고 다시 열어 4장과 한글 텍스트·노트를 확인했다. 편집 영역의 다음 장 버튼도 확인했다.
- PDF 내보내기로 960 × 540포인트의 4페이지를 생성했다. 모든 페이지를 렌더링해 한글·색상·배치를 육안 확인했고, 발표자 노트와 편집 도구는 출력에서 제외됐다.
- 검사 후 원래 사용자 문서로 돌아왔다.

## 패키지 검증

두 ZIP 전체 CRC32 검사를 통과했다. 각 ZIP의 앱 ASAR SHA-256은 `6ce4c5821c67d6e33f14a2d444477fb559e3e4c7fcb9c063d83fc1e4ba248479`로 같다. ASAR에는 1.4.0 매니페스트, 현재 프로덕션 자산과 Electron 셸만 들어 있으며 모든 해당 파일을 작업 사본과 바이트 단위로 비교했다. 포함된 글꼴은 Carlito와 나눔바른고딕이며 라이선스를 함께 제공한다.

Mac ZIP에서 추출한 앱과 설치 앱 모두 `codesign --verify --deep --strict`를 통과했다. Windows 패키지는 공식 Electron 42.11.15 런타임 SHA-256, PE x64 구조, 제품 메타데이터, 필수 파일과 원본 실행 코드 섹션 보존을 확인했다.

## 한계와 증거 파일

이전에 PC에서 수행한 실제 실행 기록은 있지만, 이번에 재생성한 Windows 1.4.0 ZIP을 이 Mac 세션에서 Windows로 실행하지는 않았다. 실제 OS 키보드 IME와 물리 프린터 출력은 미검증이다. Mac은 ad-hoc 서명이며 공증하지 않았고 Windows는 배포 서명이 없다. 없는 원본 글꼴, 복잡한 효과·벡터 형식과 지원하지 않는 PowerPoint 기능에는 차이가 남는다.

로컬 결과는 `qa/results/release-1.4.0/`의 `tests.json`, `native-verification.json`, `asar-verification.json`, `corpus-summary.json`과 `qa/results/release-1.4.0-corpus/corpus.json`에 있다. ZIP 검증은 `release/VERIFICATION.json`, Windows 런타임 검증은 `release/BUILD-win-x64.json`에 있다. 이 생성 파일과 원본 샘플은 Git에 포함하지 않는다.
