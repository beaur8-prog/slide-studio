# Slide Studio 1.6.8

제목 슬라이드로 시작하는 첫 화면과 홈 도형 서식·삽입 기본값 개선.

- 앱 실행·새 편집 창은 새 프레젠테이션의 제목과 부제가 있는 한 장으로 시작한다. 이전 파일을 자동으로 다시 열지 않으며, 같은 창의 새로고침은 현재 편집 버퍼를 복원한다.
- 홈의 도형 서식을 글꼴과 단락 사이에 한 줄로 배치했다. 좁은 창에서도 채우기·선 색·두께를 조절할 수 있다.
- 메뉴 위쪽 세 줄의 사각형·둥근 사각형·타원·삼각형·선·화살표·마름모·오각형·육각형은 채우기 없음·검은 선·두께 3으로 삽입한다. 나머지 13개 도형은 파란색(`#4472C4`) 채우기를 기본으로 한다. 원본 PPTX·기존 도형·테마 장식의 서식을 일괄 변경하지 않는다.
- 위쪽·아래쪽 블록 화살표를 추가했다. 닫힌 도형 경로로 저장해 PPTX 재열기 후에도 모양과 채우기를 유지한다.

세부 구현과 선행 검증: [홈 도형 서식](SHAPE-FORMAT-CONTROLS.md), [저장·실행·최근 파일](PPTX-SAVE-AND-FOLDERS.md).

Mac ARM64 ZIP, Windows x64 Setup/ZIP, Ubuntu 22.04/24.04 amd64 DEB를 제공한다. 리토스 문서는 기존 공유 URL과 고정 GitHub 다운로드 주소를 유지한다. Windows 설치 안내와 다운로드 경고를 문서 맨 위에 유지한다. Mac은 Apple 미공증이며 Windows는 배포용 코드 미서명이다.

## 검증 범위

최근 파일·창 시작·PPTX 저장·문서 폴더·그림 배경·0 크기 도형·홈 서식·숫자 입력·부분 글자 서식·글머리표·노트·스크롤·발표 격리와 도형 경로 저장을 검사한다. 전체 앱 검사 모음을 모두 다시 실행한 결과는 아니다.

실제 배포 앱은 별도 검증 프로필에서 실행한다. 첫 제목 슬라이드와 새 문서 제목 레이아웃, 삽입 메뉴 22개의 색·선·두께, 홈 도형 서식 위치, 위/아래 블록 화살표의 PPTX 저장/재가져오기를 검사한다. 기존 그림 배경·0 크기 도형·PPTX/PDF 저장·문서 폴더·노트 크기·표 행 높이·삼각형 꼭짓점·GIF/MP4/WebM도 함께 검사한다. 파일 대화상자 응답은 검사용으로 지정하고 실제 IPC와 파일 입출력을 사용한다.

Windows는 호스팅된 Windows Server에서 설치·재설치·제거·바로가기·사용자 자료 보존을 검사한다. Ubuntu는 22.04/24.04 X11에서 설치·실행·제거와 Chromium 샌드박스를 검사한다. 실제 Windows/Linux 키보드 IME 직접 타이핑·Wayland·종이 출력은 검증하지 않는다. 모든 PowerPoint 효과·원본 글꼴·조판 일치를 보장하지 않는다.

소스 회귀 검사 **67개**, 프로덕션 빌드와 Mac 배포 앱 검사가 통과했다. Mac은 완전 종료 후 실행·창 재열기의 제목 슬라이드 시작, 같은 창의 편집 복원 및 최근 파일 원본의 변경·삭제도 확인했다. 네 배포 파일의 실행 코드 SHA-256이 같고 현재 빌드 소스 54개와 일치하며, Mac ZIP을 다시 풀어 코드 서명 무결성을 검증했다. Apple 공증을 뜻하지 않는다. 로컬 증거는 `qa/results/release-1.6.8/`에 보관한다.

Ubuntu 최초 검사는 PPTX 재구성 후의 경로 `M25`와 `M 25`를 다른 문자열로 판단해 실패했다. 경로의 모든 좌표·명령 토큰과 채움·선·기준 크기를 비교하도록 검증 코드를 보완했다. 배포 앱의 실행 코드와 파일은 변경하지 않았으며 같은 해시의 DEB를 다시 설치해 두 Ubuntu 환경 모두 통과했다. 배포 태그는 유지하고 검증 코드 커밋 `93648e0a29079c162c50e27e3a43010f3ec671c2`로 Linux 워크플로를 실행했다.
