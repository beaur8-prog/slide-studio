# Slide Studio 1.5.2 배포 검증

2026-10-18(KST), macOS arm64에서 아이콘 수정까지 포함한 1.5.2를 검증했습니다. 앱 코드 기준 커밋은 `1e9ab7c`입니다.

## 변경 내용

슬라이드 위 표의 셀 범위 선택·부분 서식·복사/붙여넣기와 행·열 경계 드래그를 추가했습니다. 표는 편집 가능한 PPTX 표로 저장됩니다. 차트·다이어그램·아이콘·WordArt·수식·기호, 사진 앨범, 창·화면 캡처, 링크, 날짜·슬라이드 번호·바닥글을 포함합니다. 앱 패키지와 직접 Electron 실행에 같은 주황색 아이콘을 적용했습니다. 기존 편집·발표 휠 반응 수정도 포함합니다.

## 검사 결과

- 기능 변경 커밋 `b43795b`: 전체 Playwright 검사 134개 통과, 2개 제외, 실패와 불안정 검사 0개(285.4초).
- 제외: Windows 실제 전체 화면 검사, 로컬 Office 캐시에 없는 Arial Nova Light 원본 글꼴 검사.
- 아이콘 변경 커밋 `1e9ab7c`: 빌드 및 네이티브 셸·캡처 IPC·프로덕션 회귀 검사 10개 통과(13.4초).
- Mac 실제 앱: 4×3 표의 한글 텍스트, 2×2 셀만 글자 크기 변경, 열 경계 33%→41%, 행 경계 50%→65%, 취소와 다시 실행.
- 네이티브 저장·열기 창으로 .slide와 PPTX 저장 후 다시 열기. 표의 한글, 선택 셀 서식, 서로 다른 행·열 크기를 화면과 PPTX XML에서 확인.
- Mac 슬라이드 쇼: 짧은 스크롤 한 번으로 2→3장 이동, Esc로 편집 복귀.
- 설치한 최종 앱에서 주황색 아이콘과 버전 1.5.2 확인.
- 300장 문서 1회 측정: 열기 1505.5ms, 10개 키 입력 566.2ms, 편집 종료 후 저장 875.7ms. 기기·문서별 성능 보장값은 아닙니다.

## 범위와 한계

이번 Windows ZIP은 Mac에서 교차 패키징했으며 Windows 실제 실행은 수행하지 않았습니다. 한글 IME는 자동 조합 이벤트로 검사했고 Mac에서는 한글 붙여넣기를 확인했습니다. 실제 OS IME 직접 타이핑, 실제 macOS 화면 기록 권한·캡처, 종이 출력은 미검증입니다. 캡처 IPC 검사는 모의 이미지 소스를 사용합니다. 이번 작업에서 네이티브 PDF를 새로 출력하거나 전체 공개 PPTX 465장 검사를 반복하지 않았습니다. Mac은 ad-hoc 서명으로 Apple 공증이 없고 Windows는 배포 서명이 없습니다.

기존 GitHub `releases/latest/download/` 파일 이름과 리토스 공유 문서 주소를 유지합니다. 리토스는 기존 항목의 `ShareServer.update`(공유본 갱신)를 사용하고 공유 서버·터널을 재시작하지 않습니다.

로컬 증거: `qa/results/git-latest-1.5.2/`, `qa/results/icon-1.5.2/`, `qa/results/release-1.5.2-document/`. 생성 파일과 사용자 문서·공유 설정은 Git에 포함하지 않습니다.
