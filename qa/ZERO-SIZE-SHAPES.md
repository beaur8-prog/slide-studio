# 크기가 0인 도형으로 인한 PPTX 열기 실패

다음 배포용 소스 수정. 공개 설치 파일과 리토스 공유 문서는 변경하지 않는다.

## 원인과 처리

공개 NASA SEWP 자료의 8장에는 높이 0인 사용자 경로가 세 개 있다. 경로의 높이도 생략되어 외곽 높이 0을 물려받는다. 기존 경로 파서는 이를 거부하고 사각형으로 대체했으며, 마지막 문서 검사에서 높이 0인 사각형이 거부되어 파일 전체 가져오기가 중단됐다. 과학실 안전수칙 자료 12장에도 높이 0이고 윤곽선이 없는 사각형 세 개가 있어 같은 검사를 통과하지 못했다.

- 도형에는 0 크기를 허용한다. 음수·비정상 수치, 텍스트·이미지·표·동영상의 양수 크기 검사, 경로의 안전성 검사는 유지한다.
- DrawingML 경로의 좌표계 한 축이 0이면 내부 좌표계에만 1을 사용한다. 원래 도형의 위치·크기·종류·경로 좌표는 유지하며 도형을 강제로 늘리거나 제거하지 않는다.
- 크기가 0인 도형은 SVG의 0 viewBox나 0 나눗셈을 피하고, 보이는 윤곽선만 기존 선 렌더러로 표시한다. 선 색·두께·점선·끝 모양·불투명도를 유지하며 채우기만 있는 개체는 숨겨진 상태를 유지한다. 면적이 생기면 기존 원래 도형 렌더러를 다시 사용한다.
- 크기가 0인 삼각형에는 꼭지점 조절 핸들을 표시하지 않아 0 나눗셈을 막는다. 일반 크기의 꼭지점 편집은 유지한다.
- PPTX 저장에서 0 두께 윤곽선을 라이브러리 기본 두께로 바꾸지 않도록 원래 값을 기록한다.

## 검증

신규 회귀 검사 세 개는 수정 전 모두 실패했다. 수정 후 관련 모음 34개가 통과했다. 이 모음에는 기본 입출력, 모든 187개 도형 프리셋의 세 가지 종횡비·반복 저장, 도형 조절값 300개, 그룹 반전·회전, 꼭지점 편집, 다중 선택·크기 조절과 홈 도형 서식이 포함된다. 이후 0 두께 저장 보존을 추가해 입출력·신규 검사 10개를 실행했고, 기본 선 끝 모양 `undefined`와 `butt`를 같은 값으로 비교하도록 검사만 보완한 뒤 신규 검사 세 개를 다시 확인했다. 프로덕션 빌드도 통과했다.

신규 검사는 가로·세로·두 축이 0인 도형, 높이가 생략되거나 0으로 명시된 사용자 경로, 위치·회전·원본 경로·색·두께를 PPTX로 세 번 저장·재가져오기, 투명한 장식의 0 두께 보존, 잘못된 입력 거부, 삼각형 핸들 보호를 확인한다. 가로·세로 선과 화살촉을 실제로 렌더링해 픽셀을 검사하고, 보이지 않아야 하는 채우기 전용 개체가 나타나지 않는지 확인했다.

실제 공개 샘플 다섯 개도 모두 가져오기·화면 렌더링·PPTX 저장 후 재가져오기에 성공했다. 각 파일의 슬라이드·개체 수와 0 크기 도형의 원래 위치·크기·경로·선 색·두께를 비교했다.

| 샘플 | 슬라이드 | 개체 | 0 크기 도형 |
| --- | ---: | ---: | ---: |
| 과학실 안전수칙 | 13 | 71 | 3 |
| 졸업연구 발표 양식 | 6 | 59 | 0 |
| NASA IXPE 발표 템플릿 | 5 | 28 | 0 |
| NASA SEWP 교육자료 | 18 | 187 | 3 |
| NASA 태양과 우주기상 | 1 | 1 | 0 |

로컬 증거는 `qa/results/zero-size-shapes/`와 `qa/results/zero-size-shapes-*.log`에 있다. 실제 파일 원본은 다운로드 폴더에 그대로 유지하며 검사 결과나 파일을 Git에 포함하지 않는다. Windows/Linux 설치판의 직접 실행 검증은 별도다.
