# 업데이트 메뉴·수동 설치·진행 표시 검증

- 개발 버전: **1.6.19**
- 기능 구현: `a6dd491`, 테마 보정: `a5597e3`, Windows 파일 검증 보정: `f65f8ba`, Windows 창 표시 보정: `538dd11`
- 공개 릴리스 게시, 공개 다운로드 파일 교체, 리토스 변경은 수행하지 않았습니다.

## 사용 방법

1. **파일 → 업데이트 확인…** 또는 **도움말 → 업데이트 확인…**을 누릅니다. 이 단계에서는 새 버전 확인만 하고 파일을 받거나 설치하지 않습니다.
2. 새 버전이 있으면 **다운로드**를 누릅니다. 받은 크기와 전체 크기, 진행률, 파일 검증 상태를 표시합니다. 창을 닫아도 하단 상태 버튼에서 진행 상황을 확인하고 다시 열 수 있습니다.
3. 검증이 끝나면 Windows는 **지금 설치**, Mac은 **교체 방법 보기**를 누릅니다. Windows 설치형 앱은 문서 종료를 마친 뒤 별도 진행 창에서 종료 대기·파일 검증·설치·버전 확인·재실행을 표시합니다. 문서 종료를 취소하면 설치도 취소합니다.
4. **수동 업데이트…**에서는 자동 확인·다운로드를 끄고 위 단계를 직접 실행하거나 공식 다운로드 페이지를 엽니다. 자동 확인을 켜도 설치는 사용자가 시작해야 합니다.

Mac은 자동 교체에 필요한 배포 서명이 없어 ZIP을 풀고 기존 앱을 직접 교체합니다. Linux와 지원하지 않는 실행 환경은 공식 페이지에서 직접 설치합니다. 다운로드를 시작하기 전에는 설치 버튼이 비활성화됩니다. 네트워크·검증 오류와 취소는 창에 표시하며 재시도할 수 있습니다.

## 완료한 검사

- `npm run test:updates`: **24개 통과**. 확인만 실행, 다운로드와 설치 분리, 실제 받은 바이트, 취소 시 부분 파일 정리와 재시도, 자동 설정을 꺼도 수동 다운로드 유지, 철회된 메타데이터의 캐시 실행 차단, 설정 저장 순서, 설치 결과 검증을 포함합니다.
- Playwright 관련 화면·네이티브 IPC·저장 보호 검사: **20개 통과**. 마지막 테마 보정 뒤 업데이트 화면 **7개 통과**(기존 6개 재검사와 테마 대비 1개). 진행 문구·설명·제목의 대비를 두 테마에서 확인합니다.
- 실제 Mac Electron의 main/preload/renderer/IPC로 메뉴, 확인, 진행률, 창을 닫은 뒤 상태 유지, 취소·임시 파일 정리·재시도, 수동 교체 안내와 재실행 후 설정 유지를 확인했습니다. 이 검사는 외부 통신과 OS 대화상자만 시험 데이터로 대체했습니다. 화면의 `99.0.0`은 시험용 버전이며 실제 릴리스가 아닙니다.
- Mac 패키지의 임시 서명과 번들을 검증했습니다. 실행 중이던 1.6.16은 저장된 제목 슬라이드 한 장임을 확인하고 앱 메뉴로 정상 종료한 뒤 백업했습니다. `/Applications/Slide Studio.app`을 1.6.19로 교체·실행했고 실제 파일 메뉴와 공식 서버의 업데이트 확인 결과를 확인했습니다. 사용자 자료는 유지했습니다.
- `npm run build` 통과. Vite의 기존 청크 크기 안내는 남아 있습니다.

## Windows 설치 시험

첫 설치 시험과 [공식 설치 파일을 사용한 원인 재현](https://github.com/beaur8-prog/slide-studio/actions/runs/41201018999)에서 Windows PowerShell이 `Get-FileHash` 명령을 찾지 못해 파일 검증 단계에서 오류 창을 표시하는 문제를 확인했습니다. 진행 창이 실제로 표시되는 두 단계와 오류를 기록으로 확보했습니다. SHA-256을 .NET의 스트림 기반 암호화 API로 계산하도록 바꿔 외부 PowerShell 모듈 탐색에 의존하지 않게 했습니다. 무결성 검증은 유지합니다.

이후 설치는 완료됐지만 콘솔의 숨김 실행 설정 때문에 진행 창의 첫 표시도 숨겨지는 것을 확인했습니다. `ShowWindow`로 진행 창을 명시적으로 표시하고 각 단계의 표시 여부를 실제 Windows API로 확인하도록 수정했습니다. [공식 1.6.16 설치 파일로 재검사](https://github.com/beaur8-prog/slide-studio/actions/runs/41202516665)에서는 실제 창·진행 문구 화면, 다섯 단계 표시, 설치 버전, 앱 재실행, 사용자 자료 보존과 제거 후 자료 보존까지 통과했습니다.

개발 1.6.19 설치 파일도 다섯 단계 표시·설치 버전·재실행·사용자 자료 보존까지 확인했습니다. 재실행된 앱이 설치 기록을 읽고 이동하는 정상 동작과 검사 도구의 보고서 복사가 경합해 검사만 실패했습니다. 검사 도구가 이미 읽은 결과를 보관하도록 보정한 뒤 [최종 1.6.19 Windows 검증](https://github.com/beaur8-prog/slide-studio/actions/runs/41202892378)이 **모두 통과**했습니다. 업데이트 검사 24개, 관련 화면·저장 보호 검사 21개, 실제 Setup 설치·다섯 단계의 OS 창 표시·버전 확인·재실행·사용자 자료 보존·정상 종료·제거 후 자료 보존까지 확인했습니다.

이 시험은 제공한 버전을 같은 버전으로 다시 설치합니다. 실제 구버전 바이너리에서 신버전으로 교체하는 시험은 아니며, 신버전 선택과 정상 종료·취소 처리는 업데이트 단위 검사에서 별도로 확인합니다. 최종 앱 코드의 커밋은 `538dd11`이며, 이후 변경은 검사 도구의 화면 캡처 시점과 보고서 보관 보정입니다. 최종 Windows 검사 커밋은 `6a18200`입니다.
