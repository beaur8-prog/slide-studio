후속 개선: SVG와 지원하는 EMF·WMF는 이제 앱에서도 그림으로 표시합니다. 이 문서의 미지원 표시 범위는 보존 기능을 먼저 검증한 당시의 기록이며, 최신 범위는 [벡터 그림 개선 검증](VECTOR-IMAGES-2026-10-30.md)을 참고하세요.
시작 소스는 `b2577b8`, 로컬 패키지 버전은 1.6.15다. 기능 수정·Git 반영과 로컬 앱 교체 범위이며, 공개 릴리스나 리토스 문서의 다운로드 파일은 갱신하지 않는다.

## 재현과 변경

기존 코드는 가져온 편집 모델에서 PPTX 전체를 재생성했다. 모델에 포함하지 않는 개체 애니메이션, 오디오, SVG 원본과 PNG 미리보기의 SVG 확장, 패턴 채우기, 고급 전환이 저장 후 사라졌다. 이전 소스의 동일 재현 파일에서 실제로 애니메이션·오디오·SVG가 없는 출력이 생성되는 것을 확인했다.

이제 원본 구조가 필요한 문서는 크기·경로 검사를 거친 원본 ZIP 한 개와 개체별 변경 정보를 로컬 모델에 보관한다. 변경하지 않은 개체·복합 개체와 마스터·레이아웃은 원래 XML과 연결된 첨부 파일을 사용한다. 지원하는 개체를 편집하면 변경한 속성을 반영하면서 남길 수 있는 원본 채우기·그림·텍스트 구조를 유지한다. 저장된 PPTX에는 표준 Office XML·미디어·첨부 부분만 들어가며 원본 ZIP이나 숨긴 JSON 프로젝트를 추가하지 않는다.

- 제목 편집, 위치 변경, 그림 자르기와 반복 저장 후에도 원본 SVG·오디오 데이터와 애니메이션·전환을 유지한다.
- PNG 미리보기를 자를 때도 SVG 원본을 유지하고, `srcRect`와 변환의 XML 순서를 맞춘다.
- SmartArt처럼 가져올 때 여러 편집 개체가 된 경우도 묶음 전체를 비교한다. 이 묶음을 수정하지 않았다면 원래 SmartArt 프레임·데이터·레이아웃·스타일·색상·저장된 도형 배치로 저장한다.
- 관계 ID, 도형 ID와 애니메이션 대상, 전체 문서의 마스터/레이아웃 ID를 다시 연결한다. 복제한 도형이 원본의 애니메이션 대상을 빼앗지 않으며, 삭제한 대상의 애니메이션과 불필요한 자산은 제거한다.
- 슬라이드 복제·재배치와 다른 문서로의 내부 슬라이드 복사, 실행 취소·다시 실행에도 원본 자료가 따라간다. 차트/통합 문서는 복제 사이에서 독립적으로 유지하고, 공통 그림과 변하지 않은 템플릿은 재사용한다.
- 변경하지 않은 노트 서식, 원본 문서의 내장 글꼴·사용자 지정 슬라이드 쇼 등도 유지한다. 슬라이드 순서가 바뀌어도 사용자 지정 쇼의 대상은 올바른 슬라이드를 가리킨다.
- 비대칭 텍스트 테두리가 중복 생성되지 않으며, 표의 원본 셀 내용을 유지하는 경우에도 현재 행 높이와 프레임 크기를 기록한다.
- 보존한 동영상의 자동 시작·반복·음소거를 바꾸면 새 설정을 적용한다. 전환 메뉴에서 없음/페이드를 명시적으로 선택하면 원본의 지원하지 않는 전환 설정을 대체한다.

## 저장 전에 확인하는 한계

지원하지 않는 구조를 완전히 유지할 수 없는 편집은 실제 제외/변환 내용을 모아 **파일을 쓰기 전에** 표시한다. 취소하면 파일을 쓰지 않고, 저장하지 않은 변경에 대한 닫기 보호도 유지한다.

- 편집한 SmartArt·확장 개체는 개별 도형으로 저장되어 자동 재배치 정보가 사라질 수 있다.
- 편집 불가능한 구성원이 있는 그룹을 이동/크기 변경하면 해당 구성원은 원래 배치로 유지되며 이를 안내한다.
- 원본의 취소선·특수 밑줄·강조·그림 글머리표·양쪽 맞춤 등 미지원 텍스트/표 서식을 실제 편집한 경우에는 일부 서식을 유지하지 못할 수 있다. 위치만 바꾸고 텍스트 자체를 변경하지 않았다면 원본 텍스트 구조를 유지한다.
- 1 이외의 시작 번호를 사용하는 슬라이드 번호는 기존 편집 모델의 고정 텍스트 방식을 유지하며 저장 전에도 안내한다.
- 매크로·ActiveX·OLE와 외부 연결 미디어/첨부 관계는 포함하지 않는다. 원본 저장 데이터와 참조에 문제가 있으면 파일 쓰기 전에 실패한다. 외부 주소를 가져오거나 보관한 내용을 앱에서 실행하지 않는다.
- 원본 보존 데이터도 200 MiB 편집 모델 제한에 포함된다. 들어가지 않으면 가져오기와 저장 모두에서 보존할 수 없음을 안내한다. 원본 보관으로 로컬 메모리와 자동 저장 용량이 증가할 수 있다.

이 변경은 애니메이션·오디오·벡터 원본을 **저장 파일에 유지**하는 기능이다. 앱 안에서 지원하지 않던 모든 요소를 새로 표시·재생하거나 PowerPoint의 SmartArt/글꼴 조판 엔진을 구현한 것은 아니다. 원본 문서의 글꼴·전역 설정이 서로 다른 문서 사이에서 모두 동일하게 동작하는 것까지 보장하지 않는다.

## 검증 범위

전용 검사 19개와 표 서식·삽입 필드 관련 검사를 포함한 **26개 검사를 통과**했다. 개체 삭제, 원본보다 앞에 놓은 복제 개체, 슬라이드 복제·순서 변경, 다른 문서로 복사 후 Undo/Redo, 동영상 설정 변경, 호환성 확인 취소, 잘못된 원본 정보·경로 이탈·손상 ZIP·DTD/ENTITY를 검사했다. 반복 저장은 실제 PPTX를 다시 가져와 수행하며 SVG와 오디오 원본 바이트도 비교한다.

- 전체 회귀: **470개 통과, 환경 조건 19개 제외, 실패·불안정 재시도 0개**(16.9분).
- 이후 SmartArt 묶음과 SVG 원본 바이트 보관을 보완한 최종 관련 검사: **26개 모두 통과**(29.3초). 원본의 UTF-8 BOM·XML 선언이 있는 SVG도 바이트 그대로 유지하며, SVG 내부의 외부 그림 주소에 요청하지 않는 것을 확인했다.
- 비표준 시작 번호를 저장·재열기한 뒤 실제 화면에 사용하는 필드 계산을 다시 적용해도 7·8이 유지되는 추가 검사도 통과했다.

전체 집계는 최종 두 보완 전에 시작한 실행이며, 현재 491개 검사를 모두 다시 실행한 것으로 표시하지 않는다. 관련 재검사는 전체 검사와 중복되므로 합산하지 않는다. 제외 항목은 이 작업본에 없는 CMU/DSU·사용자 참조 문서, Office Light 글꼴과 Windows 네이티브 환경 등이 필요한 경우다.

최종 Mac 패키지의 별도 프로필에서 보존 경로 **8개 흐름**과 기존 편집 통합 **6개 흐름**, 차트/출력 **6개 흐름**을 확인했다. 새 기능은 실제 파일 IPC로 제목 편집·Undo/Redo·두 차례 PPTX 저장·재열기를 수행하고, SVG·오디오 SHA-256과 원본 XML 기능을 비교한다. SmartArt도 옆 제목만 편집한 뒤 네이티브 프레임과 관련 4종 부분을 유지하며 다시 열었다. 파일 선택 창의 응답과 프린터 콜백만 QA 프로세스 안에서 지정했고, 실제 종이 출력은 수행하지 않았다.

고정된 공개 업무 자료 3개·34장을 다시 열고 저장 왕복을 통과했다. 텍스트·이미지 수를 보존했고 자동 글자 잘림·겹침 후보와 JavaScript 오류는 0개였다. 실제 300장·1,860개 개체·그림 300개·표 60개인 37,182,813바이트 자료도 UI 편집·Undo/Redo·저장·재열기와 추가 재열기 2회를 통과했다. 텍스트·표·노트와 그림 해시를 비교했다. 다른 QA와 동시에 실행했으므로 이 실행의 시간을 이전 단독 성능 측정과 비교하지 않는다.

반복 저장·복제·그룹·잘린 SVG·외부 오디오 제외·글꼴/사용자 지정 쇼·SmartArt 재현 결과와 최종 네이티브 출력의 스키마·관계·콘텐츠 타입 검사를 통과했다. 네이티브 PPTX 재열기와 앱 화면도 확인했다. Microsoft PowerPoint 자체의 재생·픽셀 일치를 확인한 검사는 아니다.

기존 소스에서 재현한 실패, 중간 회귀에서 찾은 경고 표시/ID 충돌, 최종 검사 자료는 로컬 `qa/results/pptx-preservation/`에 구분해 보관한다. Windows/Linux에서의 이번 네이티브 실행과 Microsoft PowerPoint 자체의 렌더링/재생은 이 Mac 세션의 검증 범위가 아니다.

## 재실행

```sh
npm run build
npx playwright test tests/pptx-preservation.spec.ts tests/pptx-compound-preservation.spec.ts tests/insert-roundtrip.spec.ts tests/table-style-roundtrip.spec.ts
npx playwright test
node scripts/qa-pptx-preservation.cjs '/path/Slide Studio.app/Contents/MacOS/Slide Studio' '/path/source.pptx' '/path/results' '/path/smartart-source.pptx'
```

전용 Playwright 검사는 재현 입력과 결과 PPTX를 출력 디렉터리에 생성한다. 구조 검사는 `pptx` 스킬의 `scripts/office/validate.py <output.pptx> --original <source.pptx>`로 수행한다. 패키지 검사는 별도 임시 프로필에서 파일 선택 창의 응답만 지정하고 실제 렌더러·파일 IPC·디스크 저장/재열기를 사용한다. 사용자 프로필이나 열려 있던 문서를 조작하지 않는다.
