## P1 — 핵심 조작 및 PPTX 저장 정확성: 수정

- 아래 방향 썸네일 이동도 화면의 삽입 표시선 앞에 배치합니다.
- 다중 선택 크기 조절은 개체 위치·크기를 함께 배율로 조절합니다. 하나의 공통 핸들을 표시하며, 회전된 개체는 해당 개체의 좌표계로 조절합니다. 모서리 Shift 비율 고정은 세로 이동에도 작동하고 이미지 모서리는 기본 비율을 유지합니다.
- 글머리표는 빈 항목 Enter로 종료, 기호 바로 뒤 Backspace로 기호/내어쓰기 제거, Tab/Shift+Tab으로 들여쓰기를 지원합니다. Shift+Enter는 같은 문단의 줄바꿈으로 저장합니다.
- 방향키를 길게 누른 이동은 실행 취소 한 단계로 묶어 앞선 작업 기록을 유지합니다. 리본 색상 표시는 현재 선택한 런을 따라가며, 글머리표의 보이지 않는 구분자에서 글자 크기가 0으로 표시되지 않습니다.
- 영문/동아시아 글꼴이 분리된 런에서 한글 글꼴을 바꿀 때도 해당 글꼴과 비교해 적용합니다. 영문 글꼴과 같은 이름을 선택한 경우에도 변경을 저장하며, 실행 취소 시 원래의 영문/한글 글꼴 구분을 유지합니다. `mixed-font-selection.spec.ts`로 검증합니다.
- 플레이스홀더의 생략된 `idx`를 모두 0으로 취급하지 않습니다. 종류와 명시된 인덱스를 구분하고 날짜/바닥글/슬라이드 번호는 `otherStyle`을 사용합니다. 문단 수준에 맞는 상속 스타일과 상속된 도형 기하도 읽습니다.
- PPTX 왕복 시 자동 높이, 이동/크기/회전 잠금, 프리셋 도형 반전, 셀 형태 텍스트 상자의 여백과 비대칭 테두리를 보존합니다. 비대칭 테두리는 표준 선으로 표시하면서 Slide Studio 재가져오기용 소유 정보를 함께 저장합니다.
- 0/양수 들여쓰기의 글머리표를 평문으로 바꾸지 않습니다. 아라비아 숫자 목록은 `buAutoNum`으로 내보냅니다.
- 직선/화살표는 높이 1과 중심 좌표를 일관되게 유지하여 반복 저장 시 이동하지 않습니다.
- 회전된 SVG 타원 호를 곡선으로 변환해 PPTX 전체 내보내기가 중단되는 문제를 막았습니다.

관련 검사: `priority-safety.spec.ts`, `priority-text.spec.ts`, `priority-roundtrip.spec.ts`와 기존 입출력·표·문단·편집 검사.

## P2 — 레이아웃 계산: 수정

- 가로 1단 `spAutoFit` 텍스트는 자동 높이로 가져옵니다. 세로쓰기/다단 자동 크기와 `normAutofit`의 동적 글자 축소까지 구현한 것은 아닙니다.
- 혼합 크기 문단의 퍼센트 앞/뒤 간격은 본문 런의 최대 글자 크기를 기준으로 계산합니다.
- 다단 간격을 계산하는 공통 텍스트 판독 함수에서 전달된 가로 배율을 반영합니다.

## 후속 수정 — 표시·슬라이드·발표·글꼴

- 표준 도형 187종의 경로와 17종 가이드 수식을 읽습니다. 꺾은/곡선 연결선의 저장된 기하도 유지합니다. 모든 프리셋의 기본 경로가 유한한 좌표로 계산되는 것을 검사했으며, 모든 프리셋을 PowerPoint 화면과 픽셀 단위로 대조한 것은 아닙니다.
- 선형/방사형 그라데이션, 점선/사용자 지정 대시, 외부 그림자를 가져오고 표준 DrawingML로 저장합니다. HSL 색상과 HSL 명도/채도/색조 변환을 처리합니다.
- 슬라이드 Shift/Ctrl/⌘ 다중 선택, 묶음 복제·복사·이동·삭제, 썸네일 우클릭, 정렬 화면 드래그를 추가했습니다. 서식 패널의 레이아웃은 현재 슬라이드에 적용하며 내용은 보존합니다. 정렬 화면에서는 더블클릭으로 편집 화면에 돌아옵니다.
- 별도 발표자 창에 현재/다음 슬라이드, 비공개 노트와 경과 시간을 표시합니다. Mac 전체 화면의 별도 작업 공간에서도 창을 조작할 수 있으며 청중 화면과 같은 로컬/Office 글꼴을 로드합니다. 발표자 창에는 편집·파일·클립보드·캡처 명령을 제공하지 않습니다. N/P, 입력 숫자가 없을 때 Backspace, W 흰 화면, O 노트 표시를 지원합니다.
- 형광펜과 종료 후 판서 보관/버리기를 추가했습니다. 보관은 한 번의 실행 취소로 되돌릴 수 있는 편집 도형이며 프로젝트/PPTX/PDF/인쇄에 포함됩니다.
- TTC/OTC 모음의 모든 글꼴을 검증한 뒤 기기에 등록합니다. 표 오프셋과 체크섬을 다시 작성한 독립 글꼴을 사용하고, 운영체제 글꼴 설치나 문서 임베딩은 하지 않습니다. 한 파일 64 MiB, 24개 글꼴, 합계 256 MiB까지 지원합니다.

## 아직 지원 범위가 제한된 항목

아래 기능까지 완료됐다고 표시하지 않습니다. 원본 분석은 코드 버그와 PowerPoint 기능 전체의 차이를 함께 나열하므로 구분합니다.

- 마스터/레이아웃 자체를 편집하는 계층, 그룹 안에서 별도의 부모 변환을 편집하는 UI, 연결선의 도형 부착 관계와 끝점 직접 조작.
- 그림 글머리표, 일부 동아시아/특수 자동 번호의 정확한 표시, 복합 동적 필드, 모든 글자 장식·취소선·강조·양쪽/배분 맞춤.
- 배경/도형의 이미지·패턴 채우기, 내부 그림자·반사·발광·3D 및 모든 세부 효과. 방사형 그라데이션은 중앙 타원 표시이며 모든 경로/초점 옵션을 구현하지 않았습니다.
- 모든 자동 줄의 문장부호 내어쓰기, 글꼴별 원본 줄 메트릭, 동적 `normAutofit`, 세로쓰기/다단 자동 높이의 완전한 일치.
- 네이티브 데이터 연동 차트, 오디오/비디오, 개체 애니메이션, 페이드 외 전환/자동 넘김 시간, 서식 있는 발표자 노트, SmartArt 자동 재배치.
- 원본이 없는 상용 글꼴의 동일한 모양과 글꼴 임베딩. 원본 글꼴 등록 지원이 상용 글꼴 재배포 권한을 부여하는 것은 아닙니다.

## 재현 근거를 구분해야 하는 분석

- **그룹 텍스트에 무조건 그룹 배율을 곱하는 변경은 하지 않았습니다.** 실제 CMU 샘플의 글자 크기를 검증하는 `import-inheritance-groups.spec.ts`에 따라, 원본에 저장된 포인트 크기를 유지하는 기존 보정을 보존했습니다. 그룹 계층 미지원과 글자 크기 배율 문제는 별도입니다.
- `03` 문서의 넘침 50건/겹침 후보 103쌍은 **v1.4.1 때의 측정값**입니다. 이를 현재 수정본에서 다시 측정한 결과로 표시하지 않습니다. 상자 경계 겹침 후보가 곧 실제 글자 겹침을 뜻하지도 않습니다.
- Mac 로컬 앱과 브라우저 자동 검사를 수행합니다. Windows/Linux 네이티브 실행 및 Microsoft PowerPoint에서의 직접 대조까지 완료했다고 주장하지 않습니다.
